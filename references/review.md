# 交付前 Review 手册

每一次交付给用户之前，都要先 review。review 不是重读一遍，而是**换一个身份逐项挑错**：先当“第一次看这部作品的读者”，再当“较真的编辑”。发现问题先改掉再交；改不了的（例如需要用户决定、或者需要重新出图），在交付时用一两句话明确告诉用户。

## 什么时候 review

| 交付物 | 用哪张清单 |
|---|---|
| 设定卡、节奏表、伏笔清单 | 一 |
| 小说章节 / 剧本 | 二 |
| 角色外观卡、表演卡、视觉设定 | 三 |
| 分页表、分镜表、每格 / 整页提示词 | 四 |
| 用户发回来的图 | 五 |
| 排好的漫画页、封面、叠字成品 | 六 |
| 任何一次修改 | 七（改动影响面） |

在能运行脚本的环境里，能用脚本检查的先用脚本：`check_episodes.py`（字数和结尾钩子）、`render_visuals.py sizes`（比例和插入小格遮挡）。排好的图要**自己打开看一遍**，不能只看脚本输出说“已生成”。

## 一、设定与结构

- 设定卡的每一项都填了吗？核心秘密有没有分三层？
- 伏笔清单每一条都有“埋在哪 / 读者此刻以为 / 回收章节 / 真相”吗？有没有只埋不收的？
- 节奏表：黄金三集、卡点、集尾钩子类型有没有连续重复？
- 和“已确认事项”冲突吗？（用户说过不在飞机上相遇，就不能又出现飞机）
- 借鉴的作品只借了机制吗？人物、职业、情节、台词有没有撞原作？

## 二、小说章节 / 剧本

- **逻辑**：每个人的行为有动机吗？时间线对吗（周五晚 → 周一早）？地点之间的移动合理吗（真实的地铁线路、距离、所需时间）？
- **常识**：钱、价格、职业细节、城市细节符合现实吗？（19.9 的团购券、一百八十八的威士忌、城中村一度电一块五）
- **人物**：每个人说话的口吻和表演卡一致吗？有没有为了推剧情突然变傻、变性格？
- **伏笔**：这一章应该埋 / 回收的伏笔都在吗？回收时回扣了原细节吗？
- **好看**：至少一个让人笑的反差、主角至少赢一回合、有一处读者比主角先知道的细节、结尾停在钩子上。
- **格式**：字数在范围内，下集预告、状态卡都在，状态卡更新了。

## 三、角色与视觉设定

- 每个主要角色都有和用户确认过的人设卡吗？外观卡、表演卡、台词和人设卡一致吗？
- 人设卡里的爱好、圈子、反差，有没有落到具体画面（随身物、房间、手机、破防时刻）？
- 有反差的角色：外在立住了吗？破绽埋了吗？破防画面有画风突变吗？破防后有没有立刻缩回去？
- 同样是“喜欢”，不同人设的表现是不是完全不同（小狗系和霸总不能画成一个样）？

- 八个设计轴都做了选择吗？有没有落回“AI 默认脸”（鹅蛋脸长直发米色大衣、凌乱黑发灰卫衣眼镜）？
- 和 `cast-registry.md` 里同性别的主角比，至少 4 个轴不同吗？发型轮廓、穿搭风格、主色有没有撞？
- 每个主要角色有 2 个招牌夸张脸，且互不重复吗？
- 外观卡只写看得见的、不依赖左右的锚点，描述串 25—45 个英文单词。
- 主要角色之间至少 3 项外观不同，表情演法和体态至少一半不同。
- 恋爱线角色都是成年人；没有写真人名字或“像某某”。
- 用户自带参考图时，外观卡和图一致吗？用户确认过吗？

## 四、分镜与提示词（出图前最后一道关）

先跑检查脚本（分镜 JSON 里写 `cast`，每格写 `characters` 和 `prompt`）：

```bash
python scripts/render_visuals.py lint ep01-pages.json
```

它会查出：画面里有人却没写描述串、描述串缺失或被改动、比例不对、无框格和贴纸格没写纯色背景、有框格没写背景铺满、有手机却没写屏幕朝向、负面提示缺 no text。有 ✗ 的必须改完再交付。脚本查不到的，再按下面逐格人工过一遍：


逐格过一遍：

- **人**：画面里出现的每个角色都写了完整描述串、标了要挂的定妆表吗？有没有只写名字？有没有分镜里没有的人？
- **常识与物理**（见 design.md 4.6b）：物件朝向（屏幕、二维码、杯子）、手的数量和动作、液体和光影、镜面反光。
- **时间地点**：白天 / 夜晚、室内 / 室外、城市特征和剧情一致。
- **连续性**：服装、道具、伤痕、物件位置和上一格接得上。
- **表情强度**：每格标了强度 1—5 吗？搞笑章每页至少一格到 4、一章至少一格到 5；虐、悬疑、真情的格子保持 1—2。夸张表情写的是词库里的短语，并且带上了全身动作吗？
- **人设**：这个人此刻的表情和动作符合他的身份、性格和这场戏的情绪吗？（值班经理不端酒杯，公事公办的前台不兴奋大笑）
- **剧情**：这一格和小说原文对得上吗？最后一格是钩子吗？
- **人设细节**：这一章里，每个主要角色至少出现一个只属于他的画面细节吗？
- **技术**：比例和 `sizes` 给的一致；无框格写了纯色背景；被插入小格压住的角落没放人脸；负面提示写了不要文字和气泡。
- **拼装**：画风前缀、调性后缀、画法后缀、描述串原样复制，没有临时改词；和画风冲突的词删掉了。

## 五、用户发回来的图

**一致性核查**（每次用户发回一批图都做）：

1. 生成对照图，第一行放定妆表，下面放这一批所有分格图：

```bash
python scripts/render_visuals.py sheet --refs ref-江遥.png ref-梁屿.png --images ep01-*.png --out check.png
```

2. 打开对照图，按每个角色的锚点逐张核对，写成一张表：

```text
| 图 | 角色 | 发型 / 发色 | 脸型 / 眼型 | 服装 | 配饰 / 标志物 | 配色 | 结论 |
| ep01-pg4-4 | 江遥 | ✗ 卷发半丸子头（应为低马尾） | ✗ | ✗ 粉围巾、米色高领 | ✗ 金色大圈耳环 | ✗ | 重出 |
```

3. 再看**相邻的格子放在一起**是否连贯：同一场戏的光线、时间、地点、服装状态（有没有酒渍）、道具位置。
4. 再看**画面完整**：有框格的背景有没有画满，有没有一半是空白。
5. 不合格的图：查原因（提示词漏了描述串、没写背景、没写朝向，还是模型画错了），先改提示词，再请用户重出。


逐张看，按 design.md 4.7 质检，并特别检查：

- 是不是分镜要的那个人、那个动作、那个表情？
- 有没有违反常识的地方（二维码在手机背面、多一只手、杯子悬空）？
- 有没有冒出文字、气泡、水印？
- 和其他格放在一起，画风和人物是否一致？

有问题的格子：说清楚哪里不对、是提示词的问题还是模型画错了；是提示词的问题就先改提示词，再请用户重出。

## 六、排版成品

- 自己打开成品看：气泡有没有挡脸和关键物件？字有没有溢出、太小？
- 阅读顺序对吗？插入小格有没有压住重要画面？
- 对白、旁白和小说原文一致吗？有没有错别字？
- 页码、章节标题、最后一页的钩子都在吗？
- 多页时：每页最后一格是翻页钩子吗？相邻两页版式不重复吗？
- 每页至少有一个非规整元素（贴纸人物、出格、无框、插入、斜切）吗？一章至少 3 种页面结构吗？

## 六点五、审美对照（排版成品交付前）

把成品和用户给的参考图、以及用户认可的标准版（`examples/approved/`）放在一起看，逐项问自己“好看吗”，不是“对不对”：

- **线条**：格框是细的暖深棕线吗？有没有又黑又粗？
- **文字**：对白是中等字重、深棕灰吗？气泡是椭圆、细线吗？有没有板正的粗黑字？
- **拟声词**：是手写感、错落有致的吗？
- **气泡和脸**：有没有气泡盖住超过三分之一的脸？尾巴指向说话人的嘴边了吗？
- **抠图**：把贴纸人物放大看：头发、眼白、白衣服有没有被抠掉或留下色块？
- **构图**：这一页有没有一个大的、有情绪的人物（贴纸、无框、出血）？还是全是一样大的方格？
- **人物**：贴纸人物是这一刻的动作和情绪，还是定妆表的摆拍？
- **留白**：格距、页边距是不是均匀、透气？标题是不是太大太抢？

有一项明显不如参考图，就先改再交。

## 七、修改后的影响面

用户改了一处，review 时要查它连带影响什么：

- 改设定 → 伏笔清单、节奏表、已写章节、外观卡、提示词里有没有旧说法残留？
- 改某一章 → 状态卡、后面章节的回勾、漫画分镜和对白要不要跟着改？
- 改人物外观 → 定妆表要重出，已出的图哪些要重出？

## 交付时怎么说

- review 发现并已经改掉的问题：一句话带过，例如“检查时发现格 4 的值班经理端着酒杯，已改成拿平板”。
- 需要用户处理的问题：明确写出是哪一格 / 哪一段、为什么、建议怎么办。
- 自己出过错（例如提示词漏了人物描述）：直接承认，说清楚已经怎么修正，并把规则补进 skill，避免下次再犯。
