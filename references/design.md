# 漫画画风设计规范（design.md）

本 skill 的竖屏漫画固定两套画风：**彩色 = 暖调扁平图像小说风**，**黑白 = 日式都市恋爱漫画风**。两套风格从作者挑选的参考作品里提炼共性而来，只取画法、配色、版式这类通用特征，不复刻任何具体作品的人物、构图或台词；参考图本身不放进仓库。

用法：做漫画前，先把下面的“风格卡”给用户看，问一句是直接用还是要微调（见文末“确认流程”）。确认后的结果写进 `story-bible.md` 的“画风”一节，整部作品保持不变。

排版脚本 `scripts/render_visuals.py` 里的 `STYLES` 与本文件一一对应：画面靠提示词，格框、底色、气泡、字体、文字方向靠脚本。

## 一、彩色｜暖调扁平图像小说风

### 风格卡（给用户看的版本）

> 奶油色纸底 + 粗黑格框，**分格大小错落、不规整**：有横贯整页的全景条、并排的大小格、没有边框直接画在纸上的主角大格，还有压在大格角上的特写小格，动作瞬间加放射速度线。画面是干净的黑色描线、平涂上色、几乎不画阴影；配色是暖粉、蜜桃、天蓝、奶黄、鼠尾草绿这类柔和暖色。背景常用一整块纯色衬托人物情绪，人物大眼睛、腮红、雀斑，小汗珠和抖动线表现紧张。气泡白底黑框、横排圆体字，音效字是大号黑色手写体。整体感觉：温暖、可爱、轻喜剧，也能讲尴尬和委屈。

### 画面

| 项目 | 规范 |
|---|---|
| 线条 | 均匀的中粗黑色描线，干净、不排线、不做粗细变化 |
| 上色 | 平涂为主，最多一层浅阴影；不做渐变、不做厚涂高光 |
| 背景 | 情绪格用纯色块背景（紧张=粉红、尴尬=蜜桃、平静=浅薄荷）；交代格才画完整场景，场景也要简化 |
| 人物 | 大而亮的眼睛、明显腮红、可加雀斑；表情夸张一点；每人一个固定的显眼配饰 |
| 情绪符号 | 汗珠、抖动线、头顶小星星、速度线，用来放大一个瞬间 |
| 镜头节奏 | 全景交代 → 人群 / 环境压力 → 脸部、眼睛、手脚的插入特写 → 无框动作大格（摔倒、拍桌、转身），对应上面的自由分格模板 |

### 配色

| 名称 | 色值 | 用途 |
|---|---|---|
| 奶油纸 | `#FBF3E6` | 画布底色、格距 |
| 暖黑 | `#1F1A17` | 描线、格框、文字 |
| 珊瑚粉 | `#F2B5A3` | 紧张、窘迫的背景 |
| 蜜桃 | `#F7D6B5` | 暖场、日常 |
| 天蓝 | `#BCD9EA` | 衣服、天空、冷静 |
| 奶黄 | `#F4E4A1` | 衣服、光、轻松 |
| 鼠尾草绿 | `#CDE2CF` | 植物、平静 |
| 雾粉紫 | `#E9C3D3` | 心动、羞涩 |
| 强调橙红 | `#E46A4B` | 一格里最重要的物件（书包、报告、戒指）|

### 分格（自由分格，彩色默认）

彩色风格不用规整的四宫格 / 九宫格，而是从下面 5 个自由分格模板里按本章的结尾选一个。格数仍然是 4 格或 9 格，只是大小、位置、有无边框不同：

| 模板 | 名称 | 结构 | 什么时候用 |
|---|---|---|---|
| `4-inset` | 插入特写（四格默认） | 两格并排 → 大场景格 → 压在大格左下角的特写小格 | 结尾是一个物件或一句话的揭露（报告、短信、戒指） |
| `4-hero` | 主角大格 | 横贯全景 → 大小两格 → 无框大格放主角的脸 | 结尾是一张震惊 / 决绝 / 落泪的脸 |
| `4-splash` | 动作爆发 | 三个小格蓄力 → 无框大格 + 速度线 | 结尾是一个动作（巴掌、摔门、摔倒、冲出去） |
| `9-hero` | 情绪大格（九格默认） | 全景 → 两格 → 中间无框主角大格，左右压着三个特写小格（侧脸、眼睛、手或脚）→ 横条 → 宽格钩子 | 情绪戏为主 |
| `9-splash` | 动作九格 | 三小格 → 一大两小 → 无框动作大格 + 速度线 → 插入特写 → 宽格钩子 | 动作戏为主 |

三种格子：

- **有框格**：粗黑框。横条格适合全景、走路的脚、人群；窄高格适合单人站姿。
- **无框格**：没有边框，画面四边羽化融进奶油纸底，像人物直接画在纸上。**出图时必须让人物在简洁的奶油色或浅色纯色背景上**，提示词加 `isolated on a plain cream background`，否则边缘会糊成一片。
- **插入小格**：压在大格上的特写，外圈留一道奶油色白边。放眼睛、手、发抖的膝盖、关键物件。

每个模板每一格的像素尺寸和建议出图比例，用 `python scripts/render_visuals.py sizes --layout 4-splash` 查看；`layouts` 子命令列出全部模板。要规整网格时写 `2x2`、`3x3`、`1x4`。

### 文字排版（脚本负责）

- 画布 1080×1920，底色奶油纸，格框 2—3px **暖深棕**（#4A3A30，不用纯黑粗线），格距 22px，页面四周留白 40px。
- 对白：横排**中等字重**黑体（PingFang SC Medium / 思源黑体 Medium，不用粗体），文字深棕灰（#2F2722，不用纯黑）；**白底椭圆气泡**，2px 暖深棕细线，小尖尾指向说话人。
- 旁白框：米白底、细线直角框，贴格子左上角，用手写感字体（站酷快乐体，随 skill 分发在 `fonts/`）。
- 音效字：手写感字体，**每个字单独错落、旋转、大小不一**，白描边（“啪！”“哗啦”“嘟——”）。
- 章节标题小而轻（手写感字体、40px），只在第 1 页；不要整页顶上一行粗黑大字。
- 阅读顺序：从左到右、从上到下。

### 提示词风格前缀（每格原样复制）

```text
中文：扁平上色的图像小说风格，干净均匀的黑色描线，几乎没有阴影，柔和暖色调（珊瑚粉、蜜桃、天蓝、奶黄、鼠尾草绿），奶油色纸张质感，人物身后用纯色块背景，大眼睛、明显腮红、雀斑，可爱而富有表情，汗珠和抖动线等漫画情绪符号
英文：flat-color graphic novel illustration, clean even black outlines, minimal shading, soft warm palette of coral pink, peach, sky blue, butter yellow and sage green, cream paper texture, solid pastel color-block background behind the character, large expressive eyes, rosy blush, freckles, cute and expressive, comic emotion marks like sweat drops and shake lines
```

## 二、黑白｜日式都市恋爱漫画风

### 风格卡（给用户看的版本）

> 白底细黑框，**日漫式自由分格**：斜线切开的格子、没有边框的大脸特写、压在角上的反应小格，大小错落。画面是精细的日式漫画线稿：发丝根根分明、眼睛有多层高光、脸颊用细排线画红晕；阴影全靠灰色网点，心动时背景铺闪光和柔焦光点，震惊时铺速度线。人物是成熟的都市男女，办公室、走廊、家里这类日常场景。对白是竖排宋体，装在细长椭圆气泡里，旁白是竖排方框贴在格子右上角。整体感觉：细腻、暧昧、情绪浓，适合恋爱、婚姻、职场、家庭矛盾。

### 画面

| 项目 | 规范 |
|---|---|
| 线条 | 细而精致的墨线，有轻重变化；头发用大量细线条表现光泽 |
| 阴影 | 灰色网点（screentone），不用灰度渐变喷涂；暗部可用排线 |
| 背景 | 情绪背景代替场景：心动=闪光点 + 柔焦光斑；紧张 / 震惊=集中线、速度线；日常=简化的办公室、走廊、书架 |
| 人物 | 成熟都市男女，修长比例；女性长发或低马尾，男性利落短发；眼睛大而有层次的高光；红晕用斜排线 |
| 情绪符号 | 冷汗、脸红排线、颤动小线、拟声小字（“哈……”“嗯”）|
| 镜头节奏 | 大特写脸 + 侧边小格；对话用中景双人；告白、拒绝、反转用整格大脸或背影 |

### 灰阶

| 名称 | 灰度 | 用途 |
|---|---|---|
| 纯白 | `#FFFFFF` | 画布、气泡、高光 |
| 浅网点 | 约 15% 灰 | 背景、皮肤阴影 |
| 中网点 | 约 40% 灰 | 衣服、头发中间调 |
| 深网点 | 约 70% 灰 | 夜景、压抑情绪 |
| 墨黑 | `#111111` | 线条、头发暗部、格框、文字 |

### 分格（日漫自由分格，黑白默认）

| 模板 | 名称 | 结构 | 什么时候用 |
|---|---|---|---|
| `m4-closeup` | 大脸对话（四格默认） | 无框大脸特写 + 全身格 → 下方两张脸被斜线切开 | 两人对话、试探、表情反转 |
| `m4-embrace` | 双人大格 | 特写 + 斜切动作格 → 无框双人大场景，角上压一个反应特写 | 拥抱、对峙、靠近 |
| `m4-confess` | 告白大脸 | 宽场景 → 两格斜切推进 → 无框大脸收尾（带集中线） | 告白、拒绝、崩溃、狠话，结尾是一张脸 |
| `m9-page` | 日漫整页（九格默认） | 斜底宽格 → 三格斜切 → 无框大脸 + 两小格 → 两格斜切收尾 | 九格都用这个 |

- **斜切格**：斜线把相邻两格切开，表示情绪转折或时间跳跃。出图按 `sizes` 给的外接矩形比例出，脚本会按形状裁掉边角，所以人物和关键物件不要放在格子的尖角里。
- **无框格**：同彩色风格，画面边缘羽化融进白底；提示词加 `isolated on a plain white background`。
- 要规整网格时写 `2x2`、`3x3`。

### 文字排版（脚本负责）

- 画布 1080×1920，白底，格框 3px 墨黑，格距 16px。
- 对白：**竖排宋体**，从右往左换列，装在细长椭圆气泡里；标点自动换成竖排标点。
- 同一位置有两个气泡时并排摆放，右边那个先读。
- 旁白框：竖排，直角矩形，贴格子右上角。
- 音效字：大号墨黑字 + 白描边。
- 阅读顺序：默认从左到右（竖屏用户习惯）；要做日漫原版的右到左时，在分镜 JSON 里写 `"style": {"rtl": true}`。

### 提示词风格前缀（每格原样复制）

```text
中文：黑白日式少女漫画风格，精致细腻的墨线，灰色网点阴影，发丝细致有光泽，眼睛有多层高光，脸颊用细排线表现红晕，背景是闪光点和柔焦光斑的网点，成熟的都市成年人物，高对比黑白
英文：black and white Japanese josei romance manga, fine delicate ink linework, gray screentone shading, finely detailed glossy hair strands, eyes with layered highlights, hatched blush on the cheeks, sparkle and soft bokeh screentone background, elegant adult characters in a modern city setting, high contrast monochrome
```

## 三、两套风格通用的规则

- **画面里不要任何文字**：负面提示统一写 `no text, no letters, no speech bubbles, no watermark, no signature`。参考图上那些平台水印、作者签名都不是风格的一部分。
- **给气泡留空**：每格提示词写清留白位置，如 `empty space at the top right for a speech bubble`。黑白风格的竖排气泡细长，常放在格子右侧；彩色风格的横排气泡常放在上方。
- **人物一致性**：按第四节的三层结构设计人物，先出定妆表，每格提示词按固定顺序拼装。
- **边界**：参考作品里有恋爱亲密镜头，本 skill 只画到牵手、拥抱、告白、额头相抵这一级，不画性暗示的身体特写和衣着暴露；未成年角色只用彩色风格的日常、校园题材，不进入任何恋爱亲密画面。

## 四、人物设计：三层结构

目标：每部作品的人物有自己的样子，但画风和出图质量稳定。做法是把“人物怎么画”和“人物长什么样”分开：

| 层 | 管什么 | 写在哪 | 变不变 |
|---|---|---|---|
| 画风层 | 人物怎么画：比例、五官画法、头发、阴影、表情画法 | 本文件 4.1 | 两套画风各一份，所有作品通用，**保证稳定** |
| 作品层 | 这部作品的视觉基调：主色、场景、反复出现的物件 | `story-bible.md`「视觉设定」 | 每部作品一份，**形成作品特色** |
| 角色层 | 每个人长什么样（外观卡）+ 这个人怎么演（表演卡）：眼眉、体态、小动作、表情演法、专属演出 | `story-bible.md`「角色外观卡」「角色表演卡」 | 每个角色一份，定下后整部作品不改，**让读者看出性格** |

**从参考图提炼时怎么分**：看到一个特征，问一句“换一个角色，还会这样画吗？”
- 会 → 画风层。例如：大圆眼只有一个大高光、鼻子是一个小点、腮红是平涂圆形；日漫的杏眼多层高光、发丝细线、斜排线红晕。
- 不会 → 角色层。例如：参考图里女孩的圆眼镜、发夹、雀斑、蓝色毛衣，日漫男主的细框眼镜和三七分。

### 4.1 画风层：人物画法（固定，不随作品变）

画风层只管**怎么画**（线条、上色、高光、阴影的画法），不管**长什么样**。脸型、眼型、头身比、发型都属于角色层，每个角色不一样（见 [character-design.md](character-design.md)）。画法后缀里**不能写**“圆脸”“大圆眼”“杏眼”“尖下巴”这类形状词，否则所有角色都会被拉成同一张脸。

| 部位 | 彩色｜暖调扁平图像小说风 | 黑白｜日式都市恋爱漫画风 |
|---|---|---|
| 头身比 | 由角色决定；整体画法偏可爱、比例略夸张 | 由角色决定；整体画法偏修长 |
| 脸型 | 由角色决定；轮廓线圆滑、线条少 | 由角色决定；轮廓线细、下颌线干净 |
| 眼睛 | 形状由角色决定；画法统一：一个大白高光，睫毛简化成两三笔 | 形状由角色决定；画法统一：长睫毛，瞳孔多层高光 |
| 鼻子 / 嘴 | 鼻子一个小点或短线；嘴小，开心时张成半圆 | 鼻子侧面一笔 + 鼻尖小阴影；嘴唇有一点光泽高光 |
| 头发 | 大块面平涂，少量分缕线，发尾有弧度 | 细密发丝线，网点做高光带，发丝有飘动感 |
| 皮肤 / 红晕 | 平涂肤色，腮红是平涂圆形，雀斑可选 | 白皮肤留白，红晕用斜排线 |
| 阴影 | 最多一层平涂浅阴影 | 灰色网点，暗部可加排线 |
| 手 | 简化但五指清楚 | 手指修长，关节有细线 |
| 服装 | 平涂色块 + 少量褶线，图案简单 | 布料褶皱明显，网点区分材质 |

**人物画法后缀**（接在画风前缀后面，每格照抄）：

```text
彩色·英文：eyes drawn with one large white highlight and simplified lashes, tiny dot nose, flat-colored hair in large shapes with a few strand lines, round flat blush on the cheeks
彩色·中文：眼睛只画一个大白高光、睫毛简化，鼻子是小点，头发是大块面平涂加少量分缕线，脸颊平涂圆形腮红

黑白·英文：eyes drawn with long lashes and layered highlights, a single-stroke nose, glossy lips, finely drawn hair strands with screentone highlights, hatched blush lines
黑白·中文：眼睛画长睫毛和多层高光，鼻子一笔带过，嘴唇有光泽，细密发丝加网点高光，红晕用斜排线
```

**表情库**（分镜里写表情时只从这里选，保证同一个情绪每次画法一样）：

| 表情 | 彩色画法 | 黑白画法 |
|---|---|---|
| 平静 | 眼睛正常大小，嘴角微微上扬 | 半垂眼，浅笑，眼中高光少 |
| 紧张 | 眉毛下垂，嘴抿成波浪线，额头一颗汗珠，身边抖动线 | 冷汗，瞳孔缩小，脸侧一道阴影网点 |
| 委屈 / 想哭 | 眼睛含泪变亮，腮红加深，嘴往下撇 | 眼中泪光高光变多，睫毛湿，咬唇 |
| 震惊 | 眼睛放大成圆，瞳孔变小，嘴张成 O | 瞳孔缩成点，背景集中线，冷汗 |
| 生气 / 狠决 | 眉毛倒竖，脸颊鼓起，头顶小怒气符号 | 眼神下压，半张脸压暗网点，嘴角绷直 |
| 心动 / 开心 | 眼睛眯成弯月，张口笑，周围小星星 | 脸颊斜排线红晕，眼中高光增多，背景闪光点 |

### 4.2 作品层：本作视觉设定（每部作品一份）

在 `story-bible.md` 里写一张“视觉设定”，让这部作品和别的作品一眼能分开：

```text
【视觉设定】
画风：彩色｜暖调扁平图像小说风（微调：无）
本作主色：2 个主色 + 1 个强调色，从画风调色盘里选（黑白版写网点基调：明亮 / 灰暗 / 高反差）
场景基调：2—3 个主要场景 + 光线（例：医院走廊冷白日光灯；老小区黄昏暖光）
视觉母题：1 个贯穿全剧的物件，关键章节反复出现（例：外婆的铁盒）
一句话：这部漫画看起来像什么（例：冷绿医院里的一抹暗红）
```

规则：
- 主色给全剧定调：主要场景和主角服装用主色，配角服装避开强调色。
- 强调色只给视觉母题和关键道具，让读者一眼看到“这个东西重要”。
- 同一画风下，两部作品至少主色或场景基调不同。

### 4.3 角色层：角色外观卡（每个角色一份）

写外观卡之前，先按[角色差异化手册](character-design.md)在八个设计轴（形状、剪影、脸眼、发型、体型、穿搭风格、配色、标志物）上各做选择，避开“AI 默认脸”，并和角色登记表比对，同性别主角至少 4 个轴不同。

```text
【外观卡】姓名｜身份
年龄段 / 身高体型：（彩色风格在这里写头身比：成年人 about 7 heads tall，儿童 about 5.5 heads tall）
脸型 / 眼型：（只写画风允许范围内的差异，如“眼尾上挑”“圆脸”）
发型轮廓 + 发色：（轮廓要能当剪影认出来：齐肩直发、高马尾、短卷发、三七分）
固定服装：主装一套；必要时备选一套，并写清在哪几章换
角色配色：2 个颜色，取自本作主色或画风调色盘
视觉锚点：1 个标志物（每次出场都画）+ 1 个小特征（痣、眼镜、疤、发夹）
默认表情：从表情库里选 1 个，作为这个人不说话时的脸
英文描述串：25—45 个英文单词，按上面的顺序写成一句
中文描述串：同上
```

规则：
- **区分度**：主要角色之间至少 3 项不同（发型轮廓、发色或配色冷暖、身高体型、服装类型、标志物）。剪影测试：把人物涂黑，也能认出是谁。
- **只写看得见的**：不写“温柔”“霸气”，换成“眼尾下垂”“肩宽、站得笔直”。
- **锚点不依赖左右**：AI 经常把左右画反，换个角度还会镜像。写“一只手腕上的手表”“头发别在一侧耳后”，靠物件本身被认出来，而不是靠它在哪一边。
- **小特征要写得够明显**：痣、雀斑这类小东西容易漂移或消失，写成 `noticeable beauty mark` 这类更醒目的说法，或者换成更大的标志物（眼镜、发夹、围巾）。
- **不写真人**：不写明星、网红的名字或“长得像某某”。
- **长度适中**：英文描述串太短会每格都不一样，太长模型会丢细节，25—45 词最稳。
- 定下后整部作品不改一个字；要改就改外观卡本身，然后重出定妆表。

### 4.4 角色表演卡：画法统一，演法不同

表演卡从人设卡翻译而来（见[人设库与人设共创](persona-library.md)）：人设库里对应人设的体态、小动作、表情倾向和专属演出是起点；有反差的角色，表演卡要分开写“外在演法”和“破防演法”。

画风层让所有人“用同一支笔画”，这是稳定的基础；性格靠**演法**区分。同一个画风里，读者是从这五件事看出一个人是什么性格的：

1. **眼型眉形**：画法一样，形状不同。上挑眼 + 压低的眉显得凌厉，下垂眼 + 弯眉显得温柔。（写进外观卡的描述串）
2. **默认体态**：站姿、手放哪里。抱臂、叉腰、缩肩、手插口袋。
3. **招牌小动作**：每章至少出现一次，比台词更能立人设。推眼镜、转戒指、摸手表。
4. **表情演法**：表情库规定“生气怎么画”，表演卡规定“这个人怎么生气”。冷静的人生气是眼神变冷、嘴抿紧；外放的人生气是张嘴吼、青筋、指人。
5. **专属演出**：这个人情绪顶点时固定用的镜头和背景演出（见第五节演出库）。读者看到这组演出，就知道“她要爆发了”。

每个主要角色还要有 **2 个招牌夸张脸**（表情强度 4—5，从[角色差异化手册](character-design.md)第四节的夸张表情词库里选），不同角色不重复。搞笑调性的章节，每页至少一格用到强度 4。

**性格 → 视觉的对照表**（写表演卡时从这里挑，再按角色微调）：

| 性格 | 眼眉 | 默认体态 | 表情倾向 | 专属演出 |
|---|---|---|---|---|
| 温柔 / 善良 | 下垂眼、弯眉、眼中高光多 | 微低头，双手放在身前 | 笑时眼睛眯成弯月 | 平视、柔光、花 / 闪光背景 |
| 冷静 / 克制 | 细长眼、平眉、高光少 | 背挺直，抱臂或手插口袋 | 情绪只在眼神和嘴角，幅度最小 | 平视、大留白、冷光 |
| 强势 / 控制 | 眼睛小或上挑、眉压低 | 下巴抬起，叉腰、指人 | 幅度最大，怒吼、青筋 | 仰拍、竖向阴影线 |
| 天真 / 冲动 | 圆眼、眉毛高 | 身体前倾，手势大 | 常用 Q 版变形和漫画符号 | 速度线、星星 |
| 腹黑 / 算计 | 半垂眼，一侧嘴角上扬 | 侧身对人，手托下巴 | 笑不达眼底（笑时眼睛没有高光） | 半张脸压暗、低角度 |
| 隐忍 / 倔强 | 眼尾上挑、眉头微皱 | 攥拳、握紧东西 | 哭时咬唇不出声，眼泪含着不掉 | 眼睛特写、裂纹 / 雨 |

```text
【表演卡】姓名
性格关键词：3 个（如 隐忍、精明、嘴硬）
眼型眉形：（同步写进外观卡的描述串）
默认体态：中文 + 英文短语
招牌小动作：2 个，中文 + 英文短语
表情演法：从表情库里挑 3—4 种，写“这个人怎么做”，中文 + 英文短语
专属演出：情绪顶点时固定用的镜头 + 背景演出
网点 / 配色倾向：如反派阴影网点更深、笑时眼睛不画高光
```

规则：
- **表情演法写成英文短语**，分镜时用它替换表情库里的通用表情词。例如林晚生气写 `cold glare without raising her voice, lips pressed tight`，而不是 `angry`。
- **主要角色之间，表情演法和默认体态至少一半不同**；两个人做同一种表情时，读者应该能分出是谁。
- **专属演出不要撞**：主角和对手的情绪顶点演出要明显不同。
- 不改画法：表演卡只改“演”，不改线条、上色、五官画法，所以画风仍然统一。

#### 男性人设模板（写帅哥时从这里起步）

同样是帅哥，读者靠**眼眉、发型轮廓、体型、穿搭、体态、小动作和专属演出**分辨他是哪一型。下面每种模板给出这些要点和可直接用的英文短语。用法：选一个模板做起点，再用外观卡里的具体细节（发色、标志物、配色）把他变成“这个人”，不要整段照抄成套路脸。

| 类型 | 外形要点 | 表演（体态 / 小动作 / 招牌表情） | 专属演出 |
|---|---|---|---|
| 高冷系 | 细长凤眼、眼尾微挑、浓平眉；深色利落短发，额前碎发半遮眼；高瘦；深色大衣、高领毛衣 | 双手插兜、侧身、下巴微抬；移开视线；几乎不笑，心动时只有耳朵红 | 逆光剪影、冷色、大留白 |

| 痞帅系 | 桃花眼、嘴角痞笑；碎发微乱、一侧刘海；皮夹克、银色链子、耳钉 | 歪靠在墙上、单手插兜；叼棒棒糖、转钥匙圈；坏笑、眯一只眼 | 霓虹夜色、半张脸阴影 |

规则：
- **同一部作品里的两个男性主角，必须来自不同模板**，而且发型轮廓和穿搭冷暖要拉开，涂黑剪影也能分出是谁。
- 模板之间可以混搭一项，但要有一个主类型。例如“禁欲系为主，心动时露出温柔系的笑”，反差本身就是看点。
- **恋爱线里的角色一律是成年人。** 校园题材的恋爱线用大学学长或已成年的设定；高中生只出现在友情、成长、校园日常这类非恋爱剧情里，也不用痞帅、霸总这类带撩拨感的模板去写未成年人。
- 黑白风格下：霸总、痞帅的网点更深、阴影更重；阳光系、温柔系网点更浅、眼中高光更多；高冷、禁欲系画面最干净。
- 女性角色同理，可以按同样格式补模板（如冷艳御姐、元气少女、温柔知性、清冷学霸），写进 `story-bible.md` 供本作使用。

### 4.4b 用户自带角色图：从参考图反推外观卡

用户可以先在别的平台做好人物三视图和表情图，再交给 skill 出漫画。这时顺序反过来：**图是标准，外观卡跟着图写**。

1. 逐张看图，按 4.3 的槽位写外观卡：头身比、脸型眼型、发型轮廓和发色、服装、配色、视觉锚点。只写图里真的有的东西，图里没有的不要补。
2. 从表情图里挑出这个角色已经有的表情，写成表演卡的“表情演法”英文短语；缺的表情（如这个人设需要的“冷笑”“哭”）按性格对照表补，并在提示词里注明“与参考图同一角色”。
3. 判断图的画风属于哪一套（彩色扁平 / 黑白日漫），画风前缀和人物画法后缀改写成**贴近这张图的描述**；和两套默认画风差别很大时，以用户的图为准，在“画风”一节写明“画风：以用户参考图为准”。
4. 把反推出来的外观卡、表演卡贴给用户确认一次（“我从你的图里读出这些特征，对吗？”），尤其是左右不对称的细节和颜色。
5. 之后每一格出图都挂这些参考图；提示词里的描述串照抄反推出来的外观卡。

用户的参考图里如果有水印、签名、平台 logo，不要写进外观卡；参考图明显来自某部已有作品的角色时，提醒用户这个角色不能直接用，改成原创。

### 4.5 定妆表：先定脸，再出分镜

每个主要角色先出一张定妆表，满意后作为后面每一格的参考图。全身视图用默认体态，四个表情用表演卡里的表情演法：

```text
[画风前缀], [人物画法后缀], character reference sheet of [英文描述串], front view, three-quarter view and full-body view in [默认体态], plus four expressions: [表情演法 1], [表情演法 2], [表情演法 3], [表情演法 4], plain background, consistent character design, no text, no letters, no watermark
```

1. 同一提示词出 4 张，选最符合外观卡的一张。
2. 对照外观卡检查视觉锚点、发型轮廓、配色。
3. 保存为 `visuals/ref-角色名.png`；之后每一格出图时，在工具里把它设为参考图 / 角色参考。
4. 不满意时改外观卡对应的槽位再重出，不要在单格提示词里临时改长相。

### 4.6 每格提示词的拼装顺序（固定）

```text
[画风前缀] + [本章调性后缀，见第六节] + [人物画法后缀] + [出场角色的英文描述串，几个人贴几段]
+ [这个角色的表情演法 / 默认体态 / 招牌小动作，取自表演卡] + [动作]
+ [镜头，取自演出库] + [背景演出，取自演出库] + [变形 / 漫画符号，需要时]
+ [场景：取自视觉设定的场景基调；用了背景演出时场景可以省略]
+ [留白位置] + [这一格的比例]
+ [无框格才加：isolated on a plain cream / white background]
+ [负面：no text, no letters, no speech bubbles, no watermark, no signature]
```

用了背景演出时，从画风前缀里删掉和它冲突的背景词（例如黑白前缀里的 sparkle and soft bokeh screentone background 在压抑、愤怒的格子里要删掉）；同理，角色设定和画风前缀冲突的词也删（例如林晚没有雀斑，就删掉 freckles）；调性后缀和画风前缀里的配色、背景词冲突时，以调性为准（见第六节）。

每格在变的只有“表情演法、动作、镜头、背景演出、留白、比例”，而且前四项都从表演卡和演出库里选现成的短语，不临场发挥。画风前缀、画法后缀、描述串全部复制粘贴。这是画风稳定、表现力又够的关键。

### 4.6b 画面逻辑：符合常识、物理、地理和剧情

图像模型只会画你写清楚的东西，没写清楚的它会“猜”，而且常常猜错（手机背面出现二维码、杯子倒着放、白天的窗外是夜景）。所以每格提示词都要把**谁、拿着什么、朝哪边、在哪里、什么时间**写明白。

**规则 1：出现谁，就写谁的描述串。** 画面里只要出现某个角色，哪怕只露一只手、一个背影，也要写完整的描述串并挂他的定妆表；只露手时至少写到袖子（`Jiang Yao's hand in a camel cashmere coat sleeve`）。**永远不要只写名字**，模型不认识名字，会自己编一个人。

**规则 2：物件的朝向和接触关系写明白。** 常见易错点：

| 场景 | 要写清楚的 |
|---|---|
| 手机 / 屏幕 | 屏幕朝向谁；屏幕上显示什么（二维码、通知、聊天都在屏幕正面）；是拿在手里还是屏幕朝上 / 朝下放在桌上 |
| 扫码 / 付款 | 顾客把手机屏幕朝向扫码枪，二维码显示在屏幕上，扫码枪的红光照在屏幕上 |
| 杯子、酒、液体 | 杯子正放；液体往下洒、溅在接触到的地方；洒过的污渍在后面几格还在 |
| 拿东西的手 | 一个人最多两只手，两只手各在干什么；递东西时两个人的手要接得上 |
| 文字类物件 | 菜单、文件、屏幕上的字写 `no readable text`，具体内容交给旁白框 |
| 视线 | 看向谁、看什么；说“没看见”的人视线要落在别处 |
| 镜面 / 反光 | 反光里的画面左右相反，反光里的人在镜面对面 |

**规则 3：时间和地点前后一致。**
- 同一场戏的时间（白天 / 夜晚）、天气、灯光一致；窗外景色和时间对得上。
- 真实地点用真实特征：深圳湾夜景、南山科技园的玻璃写字楼、深圳地铁车厢；不要出现别的城市的地标。季节和衣着对得上（深圳 11 月夜里穿大衣说得通，白天正午穿羽绒服就不对）。
- 招牌、路牌、交通方向等按中国大陆的习惯（简体字、车辆靠右行驶）；看不清的字写 `no readable text`。

**规则 4：剧情和人物连续。**
- 服装、道具、伤痕的状态延续：泼过酒的大衣在后面几格还有痕迹；周一换了白衬衫就一直是白衬衫。
- 物件的位置延续：上一格扣在桌上的手机，下一格要用时先写它被翻过来或拿起来。
- 人物的身份和行为一致：值班经理上班时不会端着酒杯；工作场合的人穿工作服。
- 人物的情绪按剧情来：公事公办的前台不会笑得很兴奋。

**规则 5：背景完整。** 有框的格子要把背景画满整格，提示词写 `detailed background filling the entire frame, no blank areas`；只有无框格和贴纸人物才用纯色背景。画风前缀里的“纸张质感”指的是底色，不是让画面留白。

**规则 6：配角也要有描述串。** 会出现两次以上的配角（值班经理、同事、前台），也写进外观卡和 `cast`，每次出场用同一串描述；只出现一次的路人可以不写，但要写清楚是谁（`a receptionist in a black uniform`）。

**写完提示词先自检**：每格问一遍“谁在、各拿着什么、朝哪边、在哪、几点、和上一格接得上吗”，有一项说不清就补进提示词。

### 4.7 出图质检（每格过一遍）

- 画风：线条、上色或网点和前面几格一致吗？
- 人物：标志物、发型轮廓、发色 / 配色都在吗？
- 构图：人数、朝向对吗？（主角在左、对手在右，整页不换边）
- 演出：镜头角度、背景演出、表情演法有没有画出来？这个人的表情像他自己，还是像通用的“生气脸”？
- 细节：手、脸有没有崩？有没有怪颜色（比如耳朵被涂成黄色）？
- 多出外观卡里没有的小配件（皮带、项链）不算大错，但不要把它当成新锚点，下一格也不必跟着画。
- 干净：画面里有没有冒出文字、气泡、水印？
- 常识：物件朝向、手的数量和动作、光影、时间地点、前后连续性对吗？（对照 4.6b）
- 人：画面里的人是不是分镜里写的那个人？有没有冒出分镜里没有的人？

不合格只重出这一格。同一格重出 3 次还不行，就把它改成更简单的镜头：背影、手部特写或道具特写。

## 五、演出库：让画面有表现力

每一格从下面挑：**1 个镜头 + 0—1 个背景演出 + 0—1 个变形或漫画符号**，把英文短语原样写进提示词。黑白日漫最依赖这一节；彩色风格同样适用，背景演出换成纯色块。

### 5.1 镜头

| 镜头 | 什么时候用 | 英文短语 |
|---|---|---|
| 大特写（脸占满格） | 情绪顶点、告白、狠话 | extreme close-up of the face filling the frame |
| 眼睛特写 | 震惊、动心、杀意、下决心 | extreme close-up of the eyes only |
| 仰拍 | 人物强势、压迫，或主角反杀的瞬间 | low-angle shot looking up at the character |
| 俯拍 | 人物弱小、被压、孤立 | high-angle shot looking down at the character |
| 倾斜镜头 | 不安、失控、眩晕 | dutch angle, tilted frame |
| 夸张透视 | 伸手、指人、扑过来、拍桌 | dramatic foreshortening, hand thrusting toward the viewer |
| 过肩 | 两人对峙、对话 | over-the-shoulder shot |
| 背影 / 剪影 | 离开、决绝、钩子格 | seen from behind, silhouette against the light |
| 手部 / 物件特写 | 细节揭露、紧张 | close-up of hands gripping [物件] |
| 人物占满大格 | 想要“人物突然变得很大”的冲击感 | the character towering and filling the whole frame, cropped at the edges |

“人物突然变大”在分格上配合无框格或大格使用（`m4-confess`、`m4-closeup` 的第 1 格），画面上用最后一行的镜头。

### 5.2 背景演出（用情绪代替场景）

| 情绪 | 黑白（网点） | 彩色（色块） |
|---|---|---|
| 心动 | sparkles, small flowers and soft bokeh screentone background | 雾粉紫色块 + 小星星 |
| 震惊 | radial focus lines background / white lightning on a black background | 奶黄色块 + 速度线 |
| 压抑 / 恐惧 | vertical gloomy shadow lines, dark gradient screentone | 灰紫色块 + 阴影 |
| 愤怒 | black background with jagged flame-like screentone | 珊瑚粉色块 + 怒气符号 |
| 悲伤 | rain streaks, cracked glass pattern | 天蓝色块 + 雨线 |
| 回忆 | soft white vignette, faded light screentone | 降低饱和度，边缘发白 |
| 内心独白 | blank white or abstract screentone background, character isolated | 单一纯色块，人物偏小 |

### 5.3 变形与漫画符号

| 效果 | 什么时候用 | 英文短语 |
|---|---|---|
| Q 版变形（2—3 头身） | 吐槽、尴尬、搞笑的一瞬 | chibi super-deformed style, 2 heads tall |
| 黑线脸 | 无语、尴尬 | vertical black lines over the forehead |
| 白眼失神 | 震惊到失神 | blank white eyes with no pupils |
| 青筋 | 生气 | anger vein mark on the temple |
| 大汗珠 | 慌张、心虚 | one giant sweat drop |
| 脸红冒烟 | 害羞到极点 | deep blush with steam rising from the head |
| 灵魂出窍 / 石化 | 喜剧性打击 | comedic soul leaving the body / turned to stone |

Q 版和喜剧符号只用在轻松瞬间；剧情高潮、虐点、钩子格不用，否则会把情绪冲掉。

### 5.4 内心独白怎么画

- **画面**：人物半身或大特写，视线不看对方（看向一边、低头、闭眼）；背景换成 5.2 的“内心独白”演出；多用无框格。
- **文字**：不用说话气泡，按强度从弱到强选：
  - 思考气泡 `"type": "thought"`：犹豫、小念头。
  - 旁白框 `"caption"`：叙述性的独白，比如“我情不自禁地抱住了她……”。
  - 浮空独白 `"type": "monologue"`：没有气泡和框，字直接浮在人物旁边，用于最强烈的一句，比如“然后……就是今晚……！！”。一格最多一句。
- 黑白风格这三种都自动竖排。

### 5.5 表现力分级：不要每格都夸张

| 级别 | 用法 | 4 格里 | 9 格里 |
|---|---|---|---|
| 日常格 | 平视或中景，无背景演出 | 1—2 格 | 约 4 格 |
| 情绪格 | 特写或仰俯拍 + 背景演出 | 1 格 | 约 3 格 |
| 爆发格 | 大特写 / 夸张透视 + 背景演出 + 漫画符号或角色专属演出 | 1 格（爽点或钩子） | 约 2 格 |

日常格让读者喘口气，爆发格才有冲击力。爽点格和钩子格优先用角色的专属演出。

## 六、章节调性：恋爱章和搞笑章不一样

同一部作品里，讲爱情线的章节、搞笑的章节、虐的章节，画面气质应该不同。但**换的是“打光和演出”，不是“换画师”**。

**调性能改的**：光影和色调（黑白是网点深浅）、背景演出、镜头偏好、分格模板、漫画符号和 Q 版的使用频率、音效字多少。
**调性不能改的**：线条和上色方式、人物画法后缀、外观卡（长相、服装、标志物）、表演卡。服装颜色可以在光线下变暖或变冷，但不换色。

| 调性 | 适用章节 | 彩色 | 黑白 | 镜头 / 演出偏好 | 分格偏好 |
|---|---|---|---|---|---|
| 恋爱 / 心动 | 告白、靠近、约会、暧昧 | 暖粉、雾粉紫，柔光、光斑 | 网点浅，闪光点和花朵，线条更柔 | 眼睛特写、手部特写、慢镜头式的连续特写 | 无框大格、插入特写（`4-hero`、`m4-embrace`） |
| 搞笑 / 日常 | 吐槽、误会、出糗、轻松日常 | 高饱和纯色块，速度线、星星 | 网点少、留白多，线条略粗 | Q 版、黑线脸、大汗珠、灵魂出窍可常用（最多约 1/3 的格子） | 小格多、节奏快（`4-splash`、`9-splash`，或规整网格） |
| 虐 / 悲伤 | 分离、误解、失去、低谷 | 降低饱和，冷蓝灰 | 深网点、雨、碎玻璃 | 背影、俯拍、大留白，字少 | 大格少字（`4-hero`、`m4-confess`） |
| 爽 / 冲突 | 打脸、对峙、反击 | 高反差，红黑 | 黑底、集中线、白闪电 | 仰拍、夸张透视、爆炸气泡、角色专属演出 | 斜切格、动作大格（`4-splash`、`m4-closeup`） |
| 悬疑 / 揭秘 | 发现线索、真相露出一角 | 暗色，只有局部有光 | 深网点、半张脸阴影 | 物件特写、倾斜镜头 | 插入特写（`4-inset`） |

**调性后缀**（接在画风前缀后面）：

```text
恋爱 / 心动：soft romantic lighting, gentle glow, dreamy soft focus, sparkles
搞笑 / 日常：lighthearted comedic mood, bright flat colors, exaggerated cartoon expressions
虐 / 悲伤：melancholic mood, muted cold blue-gray palette, quiet empty space
爽 / 冲突：high contrast dramatic lighting, intense tension
悬疑 / 揭秘：mysterious low-key lighting, deep shadows, a single pool of light
```

规则：
- **每章一个主调性**，在分镜开头标出来，例如“调性：爽 / 冲突”。
- **允许钩子格转调**：搞笑章的最后一格突然转虐或悬疑，反差最强，是很好用的集尾钩子。其他格不要来回换调性。
- 调性后缀和画风前缀里的配色、背景词冲突时，以调性为准，删掉前缀里冲突的那几个词（例如虐章删掉 soft warm palette 那一串配色）；线条、上色方式、人物画法的词一律保留。
- 爱情线和搞笑线的角色都要演出各自的人设：同样是恋爱章，高冷系还是只有耳朵红，阳光系可以整张脸红到冒烟。

## 七、可以微调的地方

用户想微调时，从这张表里挑，改动写进 `story-bible.md` 的“画风”一节，提示词前缀和分镜 JSON 的 `"style"` 一起改：

| 可调项 | 彩色默认 | 黑白默认 | 常见改法 |
|---|---|---|---|
| 色调 | 暖色柔和 | 灰阶网点 | 彩色可换成冷色、高饱和；黑白可加一个点缀色（如只有红色）|
| 线条 | 均匀中粗线 | 精细有轻重 | 更粗更卡通 / 更细更写实 |
| 人物比例 | 成年人 6.5—7 头身、偏可爱 | 约 7 头身、修长成熟 | 改 4.1 的头身比和外观卡里的头身描述，整部作品统一改 |
| 背景 | 纯色块为主 | 网点 + 光斑 | 改成写实场景 |
| 分格 | 自由分格（`4-inset` / `9-hero`） | 日漫自由分格（`m4-closeup` / `m9-page`） | 改成规整网格 `2x2` / `3x3` |
| 对白方向 | 横排 | 竖排 | 黑白改横排：`"style": {"vertical": false, "text_font": "sans"}` |
| 对白字体 | 黑体 | 宋体 | 互换：`"text_font": "serif"` 或 `"sans"` |
| 底色 / 格框 | 奶油底、5px 粗框 | 白底、3px 细框 | `"bg"`、`"border"`、`"gutter"` |
| 阅读方向 | 左→右 | 左→右 | `"rtl": true` |

## 八、确认流程（skill 对用户说的话）

第一次为这部作品做漫画时，在**一条消息**里给出三样东西，然后只问一个问题：

1. 对应色彩的风格卡；
2. 本作视觉设定草案（4.2）；
3. 主要角色的外观卡和表演卡草案（4.3、4.4，一般 2—3 人）。

> 这部漫画准备用【彩色｜暖调扁平图像小说风】：（贴风格卡）
> 本作视觉设定：（贴草案）
> 主要角色：（贴外观卡 + 表演卡）
> 画风和人物这样可以吗？想微调的话告诉我改哪项：分格、色调、线条、人物比例、背景、对白横排 / 竖排、字体，或者某个角色的发型、服装、标志物、性格演法。

- 用户说“可以 / 就这样”：写进 `story-bible.md`，提醒用户先出定妆表（4.5），再出分镜。
- 用户提出微调：只改他提到的那几项，写回 `story-bible.md`，再出分镜。
- 用户没有回应、或在无人值守的环境里：用默认风格，并在开头一行写明。
- 同一部作品之后再做漫画，直接沿用 `story-bible.md` 里的画风，不再重复询问；用户中途要换风格时再问。
