# 节奏与钩子手册

本手册综合番茄网文“黄金三章”、日更爽点节奏，以及竖屏微短剧的卡点与反转写法，整理成可直接执行的规则。来源见文末。

## 1. 两种媒介的共同底层

| | 番茄网文连载 | 竖屏狗血短剧 |
|---|---|---|
| 单位 | 一章，常见约 2000—3000 字，日更 1—3 章 | 一集，1—2 分钟，整部常见 60—100 集 |
| 留人方式 | 每次更新一次小矛盾爆发，积成连续小高潮 | 每集一个反转，付费点卡在反转即将揭晓前 |
| 开头 | 黄金三章：前三章必须有足够冲突或悬念 | 3 秒内抓人，约 60 秒内让观众产生好奇 |
| 叙事线 | 主线清晰，支线服务主线 | 只讲一条故事线，台词短 |

本 skill 的“短连载”取二者交集：**每章（集）比番茄标准章短，像短剧一样每集一个反转，像网文一样保留文字的心理张力。**

## 2. 情绪循环：压抑 → 期待 → 释放 → 奖赏

爽感不是一直爽，而是“先压后放”。

- **压抑**：主角被冤、被抢、被看不起、被逼到墙角。要具体到一个动作或一句话。
- **期待**：观众知道主角有底牌（金手指、马甲、证据、靠山），但对手不知道。信息差就是期待。
- **释放**：底牌打出一角，对手脸色变了。
- **奖赏**：地位、关系或资源发生实际变化（被道歉、拿回东西、被护住、升职、赢下赌约）。

一个完整循环通常跨 1—3 集。高压集和缓冲集交替：连续两集高压后，插一集情感线或日常小甜，给观众喘气，但缓冲集结尾仍要有钩子。

## 3. 黄金三集

- **第 1 集**：
  - 开头三句内出现冲突（被退婚、被赶出门、被当众羞辱、醒来发现重生 / 穿书 / 异能）。
  - 交代主角的“表面处境”和“隐藏底牌”，底牌只露一角。
  - 结尾：对手的下一步威胁，或底牌第一次生效的瞬间。
- **第 2 集**：对手加码，主角第一次小规模反击（不完全赢）。引入情感线人物或关键配角。
- **第 3 集**：第一次完整打脸 / 小翻盘，同时抛出更大的谜（“原来事情不止这样”）。

## 4. 单集结构（按比例，适用于章节和剧本）

| 比例 | 短剧约 60—90 秒 | 任务 |
|---|---|---|
| 0—10% | 0—5 秒 | 回勾上集钩子，同时带出新压力 |
| 10—30% | 5—15 秒 | 冲突升级或新人物 / 新信息进场 |
| 30—80% | 15—45 秒 | 主对峙，最多 3 个主要人物；每句台词推进剧情 |
| 80—95% | 45—55 秒 | 情绪高潮：爽点兑现或反转 |
| 95—100% | 55—60 秒 | 在冲击最强处切断，不写余波 |

## 5. 八种集尾钩子

| 类型 | 写法 | 例（原创示意） |
|---|---|---|
| 物理危险 | 角色此刻正处于危险中 | 刹车踩下去，没有反应。 |
| 信息揭露 | 关键信息即将说出时切断 | “你真正的亲生父亲，是——” 门被推开。 |
| 两难抉择 | 两个选项都要付代价 | 救妹妹，还是保住证据。 |
| 意外到来 | 不该出现的人出现了 | 葬礼上，签到簿上多了一个死人的名字。 |
| 背叛 | 信任的人原来是对手的人 | 她转身，把录音笔交给了继母。 |
| 倒计时 | 时限 + 严重后果 | 距离董事会投票，还剩十分钟。 |
| 情感告白 | 真心话即将说出时切断 | “其实三年前那晚，我就——” |
| 身份 / 真相反转 | 一句话重新定义之前所有事 | 亲子鉴定上写着：排除生物学关系。 |

使用规则：
- 相邻两集不要用同一类型。
- 背叛型适合放在中段（约 50%—60%）。
- 身份 / 真相反转是大招，全剧最多 2—3 次，放在卡点和结局。
- 偶尔反预期：观众以为是危险，其实是告白；以为是救兵，其实是对手。

## 6. 卡点安排（付费 / 追更节点）

卡点设在“反转即将揭晓”的那一刻，而不是剧情自然的段落结束处。行业里已从一个卡点发展到二卡、三卡。对本 skill 的 10—20 集短连载，建议：

| 总集数 | 第一卡点 | 第二卡点 | 第三卡点 |
|---|---|---|---|
| 10 集 | 第 3 集末 | 第 6 集末 | 第 9 集末 |
| 12 集 | 第 3—4 集末 | 第 7 集末 | 第 10 集末 |
| 15 集 | 第 4 集末 | 第 9 集末 | 第 13 集末 |
| 20 集 | 第 5 集末 | 第 12 集末 | 第 17 集末 |

（这是本 skill 按比例给出的设计建议，不是平台统一标准。）

卡点集的钩子必须是信息揭露、身份反转或背叛三类之一。

## 7. 反转密度

- 每集至少一个小反转（信息或局势改变一点）。
- 每 3—5 集一个中反转（人物关系或力量对比改变）。
- 冲突不要在同一集内解决：一个大冲突拉 3—5 集，每集加一个新的复杂因素。
- 反转出现的时机不要规律化，避免观众猜到套路。

## 8. 台词与金句

- 台词短、口语、有态度；一句台词只做一件事。
- 每 1—2 集给一句能被截图的金句，常见结构：
  - 身份反差：“你看不起的这个人，是你求了三年都见不到的人。”（示意）
  - 态度宣言：“以前我让，是因为我在乎。现在不在乎了。”（示意）
- 冲突点设计一个“值得吵”的问题，让读者想在评论区争论（主角是不是太心软？该不该原谅？）。

## 9. 常见失败

| 症状 | 修法 |
|---|---|
| 第 1 集在介绍背景 | 删掉背景，从冲突那一秒开始；背景用台词或回忆碎片补 |
| 每集结尾都是“她暗暗发誓” | 改成外部事件：有人进门、电话响、文件翻开 |
| 爽点来得太早、太满 | 底牌只亮一角，留更大的在后面 |
| 反派傻到不合理 | 给反派一个看起来合理的动机和一次真正的胜利 |
| 秘密一集讲完 | 拆成三层：表面真相 → 第一次反转 → 最终真相 |
| 情感线停滞 | 每 2 集推进一格：误会 / 靠近 / 护短 / 吃醋 / 坦白 |
| 不好笑、不吸引人 | 主角只会被拆穿不还手 → 让对手戏双方都赢回合；谎言不升级 → 让它滚雪球；只有主角在装 → 让男主和配角也在装（见伏笔与喜剧手册） |
| 后面的反转像临时编的 | 动笔前做伏笔清单，每条写清埋在哪、回收在哪；回收时回扣第 1 章的原细节 |
