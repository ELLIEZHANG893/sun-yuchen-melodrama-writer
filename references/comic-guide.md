# 竖屏宫格漫画手册

把一章（集）浓缩成一张竖屏漫画：四宫格适合做预告、宣传图；九宫格适合把整章讲完。

本 skill 不直接出图。你负责：选格 → 写分镜表 → 每格一条提示词 → 生成分镜 JSON。用户把每格的图按文件名放好后，运行 `scripts/render_visuals.py comic` 完成拼版、气泡、旁白和音效字。图里不要出现任何文字。

## 默认值

| 项目 | 默认 | 可选 |
|---|---|---|
| 页数（连载一章） | 5—6 页 | 3—10 页；短章 3—4 页，长章或大场面 7—10 页，超过 10 页拆成两章 |
| 每页格数 | 4 格 | 3—6 格；单页宣传图 / 预告可以 9 格 |
| 版式（彩色） | 自由分格：4 格 `4-inset`，9 格 `9-hero` | `4-hero`、`4-splash`、`9-splash`；规整网格 `2x2`、`3x3`、`1x4` |
| 版式（黑白） | 日漫自由分格：4 格 `m4-closeup`，9 格 `m9-page` | `m4-embrace`、`m4-confess`；规整网格 `2x2`、`3x3` |
| 色彩 | 彩色 | 黑白 |
| 来源 | 最新写完的一章 | 用户指定第几章 |
| 画布 | 1080×1920（9:16） | — |

自由分格模板每格大小都不一样，**每格的出图比例要单独写进提示词**：运行 `python scripts/render_visuals.py sizes --layout 4-inset` 查看每格尺寸、建议比例和格子类型（有框 / 无框 / 插入小格）。规整网格 `2x2`、`3x3` 约 3:5，`1x4` 约 21:9。脚本会自动裁切，比例接近即可。

彩色风格按本章结尾选模板（见 [design.md](design.md) 的“分格”一节）：结尾是物件或一句话的揭露 → `4-inset`；是一张脸 → `4-hero`；是一个动作 → `4-splash`。9 格情绪戏选 `9-hero`，动作戏选 `9-splash`。

## 一章拆成多页

连载漫画一章默认 5—6 页，每页一张竖屏图（1080×1920），最多 10 页。先做**分页表**，再做每页的分镜。

### 分页规则

1. **按小说的“节拍”切**：一页讲一件事（一个谎、一次拆穿、一个意外），不要一页塞两个转折。1300 字左右的章节通常 5—6 个节拍。
2. **每页最后一格是“翻页钩子”**：读者要有理由滑到下一页，一句没说完的话、一个刚露出来的物件、一张愣住的脸。最后一页的最后一格是本章集尾钩子。
3. **第 1 页先立人和处境**：前两格交代人物和地点，第 1 页结束前出现第一个冲突。
4. **每页一个重点格**：大格、无框格或插入特写，留给这一页最有冲击力的瞬间；其他格子做铺垫。
5. **版式轮换**：相邻两页不要用同一个模板；动作页用 `4-splash`，揭露页用 `4-inset`，情绪 / 反应页用 `4-hero`（黑白对应 `m4-*`）。
6. **页数参考**：

| 小说章节长度 | 页数 | 总格数 |
|---|---|---|
| 800—1000 字 | 4—5 页 | 16—22 格 |
| 1000—1500 字 | 5—6 页 | 20—28 格 |
| 1500 字以上 / 大场面 | 7—10 页 | 30—45 格 |

### 分页表格式（展示给用户，确认后再出每格提示词）

```text
第1页｜4-inset｜节拍：19.9 混进酒廊｜翻页钩子：一眼认出“老板”
  格1 前台扫券，红字“新人专享”｜格2 系手环（可复用已有图）｜格3 大场景 + 周可可的情报｜格4 插入：金徽章特写
第2页｜4-hero｜节拍：假电话被拆穿｜翻页钩子：那块板子越看越眼熟
  ……
```

确认分页表后，每页按下面的选格、镜头、文字规则出分镜和提示词。所有页共用同一套外观卡、表演卡和画风前缀。已经出过的图能用就标“可复用”，但比例和新格子差太多时（例如 21:9 的图放进 1:1 的格子），要按新比例重出，否则会被裁掉人。

### 多页 JSON

```json
{
  "mode": "color",
  "title": "第1章 ……",
  "footer": "他还知道多少？",
  "pages": [
    { "layout": "4-inset", "panels": [ … ] },
    { "layout": "4-hero",  "panels": [ … ], "boxes": { … } }
  ]
}
```

- `mode`、`style`、`canvas` 写在顶层，各页继承；章节标题只出现在第 1 页，`footer` 只出现在最后一页，每页自动加页码。
- 运行后输出 `xxx-01.png`、`xxx-02.png`……；加 `--strip` 另外拼一张竖长图，方便发条漫平台；`--page 3` 只重排第 3 页。
- 完整样例：`examples/ep01-pages.json`（第 1 章拆成 6 页）。
- `"layout": "custom"`：整页格子都由 `boxes` 给出（格号从 1 开始，按格号顺序阅读，每格可写 `{"box": [...], "kind": "free"}` 或 `"inset"`）。用户已经出过一批图时，用它让版式迁就图的比例，避免重出。

## 版式设计：每页都要有新鲜感

规整的“一格一格”读起来像说明书。好看的条漫每一页的构图都不一样，跟着剧情变。

### 非规整元素

| 元素 | 样子 | 什么时候用 | 模板 |
|---|---|---|---|
| 贴纸人物 | 抠掉背景、带白描边的人物，压在几个格子之间或格子上面，像贴纸 | 人物登场、这一页的主角时刻、情绪顶点、大动作 | `s-hero`、`s-action` |
| 出格 | 人物从格子里“跳出来”压在边框上 | 吐槽、震惊、社死这类喜剧反应 | `s-pop` |
| 无框大格 | 画面没有边框，边缘淡出到底色里 | 情绪满溢、动作爆发 | `4-hero`、`4-splash` 等 |
| 插入小格 | 小特写压在大格角上 | 物件揭露、眼睛、手 | `4-inset` |
| 斜切格 | 斜线切开的格子 | 紧张、转折、对峙 | `m4-*`、`m9-page` |
| 碎格 | 一排很多小格 | 快节奏的连续反应、喜剧的“一二三” | 自定义 `boxes` |

### 规则

1. **每页至少一个非规整元素**，整页都是方格的页不交付。
2. **相邻两页不要用同一种结构**；一章里至少用到 3 种不同的页面结构。
3. **按剧情选**：人物第一次登场、这一页的情绪顶点 → 贴纸人物；喜剧反应 → 出格；动作 → 贴纸动作 + 速度线；揭露 → 插入小格；转折和对峙 → 斜切。
4. 现成模板不够时，用 `"layout": "custom"` 自己摆格子，贴纸格写 `{"box": [...], "kind": "sticker"}`，可以放在任何位置、压住任何格子。

### 贴纸人物怎么出图

- 出全身或半身、动作幅度大的人物，提示词写 `full body, dynamic pose, isolated on a plain pure white background, no background, no ground shadow`。
- 脚本会自动抠掉纯色背景、加白色描边和淡阴影，按比例放进贴纸格（不裁切，默认底部对齐）。
- 也可以直接从定妆表里裁出全身像：`"image": "ref-江遥.png", "crop": [0.49, 0, 0.62, 1]`。
- 背景不是纯色的图抠不干净；抠完边缘有杂色时调 `"cutout_tol"`（默认 38）。

## 两步出图：先分格，再整页重绘

分格出图好控制（每格单独返工、人物稳定、细节清楚），整页出图更连贯（格与格的动作、光影、构图是一体的）。两步走把两边的好处都拿到：

### 第一步：分格草稿

1. 按本手册出分页表 → 每格提示词 → 用户在生图平台逐格出图（挂定妆表做参考）。
2. 用户把图发回来，按分镜 JSON 排版，逐格检查人物、表情、内容对不对。不对的只重出那一格。
3. 用户确认后，导出**版式草稿**（只有画面和格框，没有对白、旁白、音效和标题）：

```bash
python scripts/render_visuals.py comic ep01-pages.json --draft      # 输出 ep01-pages-01-草稿.png ……
```

第一步排出来的页（不加 `--draft`）本身就是一张完整的漫画页。如果第二步的重绘效果不好，直接用它就行。

### 第二步：整页重绘

每页上传 **1 张版式草稿 + 出场人物的定妆表**，配一条整页重绘提示词。模板：

```text
Redraw the attached comic page draft as one finished, cohesive vertical comic page, aspect ratio 9:16.
Keep exactly the same panel layout, panel borders, panel order and the composition of every panel.
Keep every character identical to the attached character reference sheets: [出场角色的英文描述串].
Unify line weight, colors and lighting across all panels in this style: [画风前缀] [本章调性后缀].
Fix any inconsistent faces, hands or details. Make the action flow naturally from panel to panel.
Panels: 1) [这一格的画面一句话] 2) …
[文字方案 A 或 B]
No watermark, no signature.
```

**文字方案**（第一次做整页重绘时问用户选哪个，记进 `story-bible.md`）：

- **A：让平台直接画字**。在提示词里写：`Add speech bubbles with exactly this simplified Chinese text, written correctly: panel 1, [人物]: "……"; …`。最省事，但每页都要逐字检查错别字，错了只能重出。
- **B：留白，由脚本叠字（推荐）**。在提示词里写：`Leave clean empty space for speech bubbles in each panel. No text, no letters, no speech bubbles.` 图回来以后，看图找到每句台词的位置（气泡中心）和说话人的位置（尾巴指向），写成叠字 JSON：

```json
{"mode": "color", "pages": [
  {"image": "page-01.png", "texts": [
    {"speaker": "江遥", "text": "平时都是会员朋友带我来。", "at": [0.78, 0.18], "tail": [0.7, 0.24]},
    {"text": "湾景会·周五晚", "type": "caption", "at": [0.12, 0.03]},
    {"text": "哗啦！", "type": "sfx", "at": [0.85, 0.58]},
    {"speaker": "江遥", "text": "大衣退不掉了。", "type": "monologue", "at": [0.3, 0.7]}
  ]}
]}
```

```bash
python scripts/render_visuals.py overlay ep01-overlay.json        # 输出 ep01-overlay-01.png ……
```

`at`、`tail` 都是整页上的比例坐标（0—1）。`type` 可选 `speech`、`shout`、`thought`、`monologue`、`caption`、`sfx`。在能看图的环境里，由 agent 自己看重绘后的整页来定坐标，排完再看一遍，确认气泡没有挡脸。

### 重绘后的检查

- 人物有没有被“重绘”走样？和定妆表对照标志物、发型、配色。
- 格子数量、顺序、版式有没有变？少格或多格的页不要用。
- 第一步确认过的关键物件（吊牌、手环、电路板）还在吗？
- 某一页重绘不理想：换种子或换说法重出这一页；还不行就用第一步排好的那一页。

## 选格

### 四宫格：起承转合

| 格 | 任务 | 从章节里取 |
|---|---|---|
| 1 起 | 一眼看出冲突 | 开场第一个冲突动作或第一句狠话 |
| 2 承 | 压力加码 | 对手加码 / 新信息进场 |
| 3 转 | 爽点或反转 | 本章“观众等到了”的瞬间 |
| 4 合 | 集尾钩子 | 本章最后一句或最后一个画面，不给答案 |

### 九宫格：对应单集节奏

| 格 | 单集节奏 |
|---|---|
| 1 | 开头回勾（接住上集钩子） |
| 2—3 | 加码 |
| 4—6 | 对峙主体（一场主戏，按台词推进） |
| 7—8 | 爽点 / 反转 |
| 9 | 切断：集尾钩子 |

### 自由分格的格子分工

| 格子类型 | 放什么 | 注意 |
|---|---|---|
| 横条全景格 | 地点、人群、走路的脚 | 放旁白框交代时间地点 |
| 无框大格 | 情绪最满或动作最大的那一刻 | 提示词加 `isolated on a plain cream background`；气泡放上方或下方中间 |
| 插入小格 | 眼睛、手、物件、发抖的膝盖 | 一格只放一个特写；最多一个短气泡 |
| 被插入小格压住的大格 | 主体放在不会被盖住的一侧 | `4-inset` 的第 3 格主体放右侧和上方，气泡放上方；`9-splash` 的第 9 格气泡不要放左上 |

规则：
- **最后一格必须是钩子**，和正文结尾停在同一个地方。
- 第一格不放环境空镜，直接上人和冲突；地点交给旁白框。
- 每格只表现一个动作或一句话。一格里发生两件事，就拆成两格或删一件。

## 镜头

- 相邻两格不用同一景别。常用顺序：中景（交代关系）→ 近景（情绪）→ 特写（爽点 / 道具）。
- 爽点格：主角仰拍或特写；对手俯拍、变小。
- 钩子格：道具特写、震惊的脸、背影或门口的剪影都可以，关键是“答案就要出现”。
- 人物朝向保持一致：主角在左、对手在右，整张漫画不要来回换边。
- 具体的镜头、背景演出、漫画符号和内心独白画法，从 [design.md](design.md) 第五节“演出库”里选现成短语；每格标一个表现力级别（日常 / 情绪 / 爆发），按 5.5 的比例分配。
- 角色出场时用他表演卡里的表情演法和体态，爽点格、钩子格优先用他的专属演出。
- 每章先定一个**调性**（恋爱 / 搞笑 / 虐 / 爽 / 悬疑，见 design.md 第六节），它决定这一章的光影、背景演出、分格模板和 Q 版用多少；只有钩子格可以转调。

## 文字

文字全部写进分镜 JSON，由脚本叠加：

- **对白气泡**：每格最多 2 个，每个不超过 12 字（九宫格建议不超过 10 字）。从正文里挑最狠、最能截图转发的那句，可以压缩，但不改意思。
- **气泡类型**：`speech` 普通对白；`shout` 爆炸气泡，用在吼叫和爽点；`thought` 思考气泡，小念头；`monologue` 浮空独白，没有气泡，字直接浮在人物旁，一格最多一句，用在最强烈的内心话。
- **旁白框** `caption`：时间、地点或一行关键信息，不超过 10 字。
- **音效字** `sfx`：啪、砰、哗啦……每张漫画最多 2 处。
- **底部一行** `footer`：可选，放下集预告或悬念句；标题 `title` 用章节标题。
- 气泡位置 `pos`（黑白竖排时默认右上，同一位置的两个气泡并排，右边先读）：`top-left`、`top-right`、`top`、`bottom-left`、`bottom-right`、`bottom`、`middle-left`、`middle-right`。放在说话人头部的对侧上方，不要盖住人脸；提示词里要给气泡留出空白区域。

## 分镜表格式（展示给用户）

```text
调性：爽 / 冲突（钩子格转悬疑）

格1｜中景｜日常格｜病房，母亲把笔硬塞进林晚手里，弟弟扭头看墙
  演出：镜头 过肩；背景演出 无；表演 母亲=下巴抬起、转金戒指，林晚=攥紧包带
  气泡：母亲「签吧，就一个字的事。」（右上）
  旁白：市医院 肾内科病房
  提示词（中）：……
  提示词（英）：……
```

## 每格提示词结构

```text
[风格前缀] 全组统一，见下方风格词表，每格原样复制
[人物] 外观卡里的整串描述，原样复制（出现几个人就贴几段）
[动作表情] 一个动作 + 一个情绪
[场景] 地点 + 道具，和上一格保持一致
[镜头] 景别 + 角度
[留白] 气泡位置留空：empty space at the top right for a speech bubble
[比例] 按 sizes 命令给出的这一格的比例（自由分格每格不同）
[无框格] isolated on a plain cream background（只有无框格加）
[负面] no text, no letters, no speech bubbles, no watermark
```

负面提示里一定要写 **no speech bubbles**：不然很多模型会自己画空气泡或乱码字。

## 画风

画风只有两套，全部定义在 [design.md](design.md)，这里不再另列风格词：

| 色彩 | 画风 | 提示词前缀 | JSON |
|---|---|---|---|
| 彩色（默认） | 暖调扁平图像小说风 | design.md 第一节 | `"mode": "color"` |
| 黑白 | 日式都市恋爱漫画风 | design.md 第二节 | `"mode": "bw"` |

- 第一次给这部作品做漫画时，先贴风格卡、视觉设定、角色外观卡和表演卡，问用户是否微调（流程见 design.md 第八节），确认后写进 `story-bible.md`。
- `mode` 决定脚本的版式：彩色是奶油底、粗黑框、横排黑体对白；黑白是白底、细框、竖排宋体对白和长椭圆气泡。
- 用户微调过的项，用 `"style": {...}` 覆盖，键名见 design.md 第七节。
- 黑白模式下如果出来的图还是彩色，脚本会统一转成高对比黑白，整组色调一致。

## 人物一致性（最容易翻车的地方）

人物设计和稳定出图的完整规范在 [design.md](design.md) 第四节（画风层 / 作品层 / 角色层、定妆表、拼装顺序、质检）。分镜时记住这几条：

1. **描述串原样复制**：每格提示词里人物描述一个字都不要改，不要换同义词。
2. **表情只从表情库选**：同一个情绪每次用同一组词。
3. **先出定妆表**，之后每格都挂它做参考图；全组同一工具、同一模型，支持固定种子时用同一个种子。
4. **拼装顺序固定**，每格只改表情、动作、镜头、留白、比例。
5. 出完先排一版看整体，某一格不像就只重出那一格。

## 分镜 JSON 模板

文件放在 `visuals/epNN-comic.json`，图片和 JSON 放同一个文件夹，文件名与 `image` 一致：

```json
{
  "layout": "2x2",
  "mode": "color",
  "title": "第1章 配型单说我不是亲生的",
  "footer": "她说的第一句话是——",
  "panels": [
    {
      "image": "ep01-p1.png",
      "scene": "画面一句话描述（没有图时会显示在占位格里）",
      "caption": "市医院 肾内科病房",
      "sfx": { "text": "啪！", "pos": "top-right" },
      "dialogue": [
        { "speaker": "母亲", "text": "签吧，就一个字的事。", "pos": "top-right", "type": "speech" }
      ]
    }
  ]
}
```

- `panels` 数量要等于版式的格数（自由分格模板 4 格或 9 格，网格是 列×行）。
- `"layout"` 写模板名或网格，如 `"4-inset"`、`"9-hero"`、`"2x2"`。不写时彩色默认 `4-inset`，黑白默认 `m4-closeup`。
- 可选 `"speedlines": true / false`：给任意一格加上或关掉放射速度线（速度线压到人脸时关掉）。

### 拿到真图后的微调（排版第二遍）

真图出来后先排一版，逐格检查：人脸、关键物件有没有被气泡、插入小格、羽化边缘挡住。按下面的顺序修，能不重出图就不重出：

| 问题 | 改法 |
|---|---|
| 气泡挡脸 | 换 `pos`；长台词用 `\n` 手动断行，让气泡变窄变高，塞进墙面、天空这类空白处 |
| 小格里字太大 | 这一格加 `"text_scale": 0.85` |
| 插入小格压住重要画面 | 用 `"boxes"` 单独挪这一格：`"boxes": {"8": [0.64, 0.615, 0.97, 0.715]}`，坐标是内容区的比例 [x0, y0, x1, y1]；也可以连带调整相邻格子的大小 |
| 扁格子把脸挤小 | 同样用 `"boxes"` 把它加高，相邻格子跟着缩 |
| 无框格的淡出边缘吃掉了人脸 | 这一格加 `"feather": 0.03`（默认 0.07），或 `"focus": [0.5, 0]` 让裁切保住顶部 |
| 速度线穿过人脸 | 这一格加 `"speedlines": false` |

出图前就能预防：`sizes` 命令会提示哪一格的哪个角会被插入小格压住，提示词里让那个角保持简单。
- 可选 `"style": {"rtl": true}` 等：覆盖画风版式，见 design.md。
- 可选 `focus: [0.5, 0.3]`：裁切焦点（横、纵 0—1），人脸被裁掉时调小第二个数。
- 图还没出时也可以先运行脚本，缺图的格会显示占位和画面描述，用来预览文字排版。

完整样例见 `examples/ep01-comic.json`（彩色）和 `examples/ep01-comic-bw.json`（黑白竖排）。
