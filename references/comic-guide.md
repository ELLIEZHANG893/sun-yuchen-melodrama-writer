# 竖屏宫格漫画手册

把一章（集）浓缩成一张竖屏漫画：四宫格适合做预告、宣传图；九宫格适合把整章讲完。

本 skill 不直接出图。你负责：选格 → 写分镜表 → 每格一条提示词 → 生成分镜 JSON。用户把每格的图按文件名放好后，运行 `scripts/render_visuals.py comic` 完成拼版、气泡、旁白和音效字。图里不要出现任何文字。

## 默认值

| 项目 | 默认 | 可选 |
|---|---|---|
| 格数 | 四宫格 | 九宫格；或任意 列x行（最多 4 列 6 行） |
| 版式 | 四宫格 `2x2`，九宫格 `3x3` | 四格竖条 `1x4`（每格是横向宽画面） |
| 色彩 | 彩色 | 黑白 |
| 来源 | 最新写完的一章 | 用户指定第几章 |
| 画布 | 1080×1920（9:16） | — |

每格出图比例：`2x2` 和 `3x3` 约 3:5，`1x4` 约 21:9。不确定时运行 `python scripts/render_visuals.py sizes --layout 3x3` 查看。脚本会自动裁切，比例接近即可。

## 选格

### 四宫格：起承转合

| 格 | 任务 | 从章节里取 |
|---|---|---|
| 1 起 | 一眼看出冲突 | 开场第一个冲突动作或第一句狠话 |
| 2 承 | 压力加码 | 对手加码 / 新信息进场 |
| 3 转 | 爽点或反转 | 本章“观众等到了”的瞬间 |
| 4 合 | 集尾钩子 | 本章最后一句或最后一个画面，不给答案 |

### 九宫格：对应单集节奏

| 格 | 单集节奏 |
|---|---|
| 1 | 开头回勾（接住上集钩子） |
| 2—3 | 加码 |
| 4—6 | 对峙主体（一场主戏，按台词推进） |
| 7—8 | 爽点 / 反转 |
| 9 | 切断：集尾钩子 |

规则：
- **最后一格必须是钩子**，和正文结尾停在同一个地方。
- 第一格不放环境空镜，直接上人和冲突；地点交给旁白框。
- 每格只表现一个动作或一句话。一格里发生两件事，就拆成两格或删一件。

## 镜头

- 相邻两格不用同一景别。常用顺序：中景（交代关系）→ 近景（情绪）→ 特写（爽点 / 道具）。
- 爽点格：主角仰拍或特写；对手俯拍、变小。
- 钩子格：道具特写、震惊的脸、背影或门口的剪影都可以，关键是“答案就要出现”。
- 人物朝向保持一致：主角在左、对手在右，整张漫画不要来回换边。

## 文字

文字全部写进分镜 JSON，由脚本叠加：

- **对白气泡**：每格最多 2 个，每个不超过 12 字（九宫格建议不超过 10 字）。从正文里挑最狠、最能截图转发的那句，可以压缩，但不改意思。
- **气泡类型**：`speech` 普通对白；`shout` 爆炸气泡，用在吼叫和爽点；`thought` 内心独白。
- **旁白框** `caption`：时间、地点或一行关键信息，不超过 10 字。
- **音效字** `sfx`：啪、砰、哗啦……每张漫画最多 2 处。
- **底部一行** `footer`：可选，放下集预告或悬念句；标题 `title` 用章节标题。
- 气泡位置 `pos`：`top-left`、`top-right`、`top`、`bottom-left`、`bottom-right`、`bottom`、`middle-left`、`middle-right`。放在说话人头部的对侧上方，不要盖住人脸；提示词里要给气泡留出空白区域。

## 分镜表格式（展示给用户）

```text
格1｜中景｜病房，母亲把笔硬塞进林晚手里，弟弟扭头看墙
  气泡：母亲「签吧，就一个字的事。」（右上）
  旁白：市医院 肾内科病房
  提示词（中）：……
  提示词（英）：……
```

## 每格提示词结构

```text
[风格前缀] 全组统一，见下方风格词表，每格原样复制
[人物] 外观卡里的整串描述，原样复制（出现几个人就贴几段）
[动作表情] 一个动作 + 一个情绪
[场景] 地点 + 道具，和上一格保持一致
[镜头] 景别 + 角度
[留白] 气泡位置留空：empty space at the top right for a speech bubble
[比例] 3:5（竖条版用 21:9）
[负面] no text, no letters, no speech bubbles, no watermark
```

负面提示里一定要写 **no speech bubbles**：不然很多模型会自己画空气泡或乱码字。

## 风格词表

| 风格 | 中文风格前缀 | 英文风格前缀 |
|---|---|---|
| 彩色·韩漫条漫（默认） | 韩漫条漫风格，干净线条，柔和赛璐璐上色，精致人物，电影感光影 | Korean webtoon style, clean line art, soft cel shading, detailed characters, cinematic lighting |
| 彩色·国漫厚涂 | 国漫厚涂风格，戏剧化光影，高饱和度 | Chinese manhua style, painterly rendering, dramatic lighting, rich colors |
| 黑白·日漫网点 | 黑白漫画，日式网点，浓重墨线，高对比 | black and white manga, screentone shading, bold ink lines, high contrast |
| 黑白·线稿速写 | 黑白线稿，干净钢笔线条，少量排线阴影 | black and white line art, clean pen lines, light hatching |

黑白模式：提示词用黑白风格前缀，同时 JSON 里写 `"mode": "bw"`。如果出来的图还是彩色，脚本会统一转成高对比黑白，整组色调一致。

## 人物一致性（最容易翻车的地方）

1. **外观卡串原样复制**：每格提示词里人物描述一个字都不要改，不要换同义词。
2. **全组同一风格前缀、同一工具、同一模型**出完。
3. **先出定妆图**：每个主要人物先出一张正面半身像，满意后在出图工具里用“参考图 / 角色参考 / 图生图”功能，把它作为后续每格的参考。这是目前最有效的办法。
4. 工具支持固定种子（seed）时，整组用同一个种子。
5. 标志物要显眼：每个人物给 1 个一眼认出的特征（旧手表、红发绳、白大褂胸牌），每格都写。
6. 出完先排一版看整体，某一格不像就只重出那一格。

## 分镜 JSON 模板

文件放在 `visuals/epNN-comic.json`，图片和 JSON 放同一个文件夹，文件名与 `image` 一致：

```json
{
  "layout": "2x2",
  "mode": "color",
  "title": "第1章 配型单说我不是亲生的",
  "footer": "她说的第一句话是——",
  "panels": [
    {
      "image": "ep01-p1.png",
      "scene": "画面一句话描述（没有图时会显示在占位格里）",
      "caption": "市医院 肾内科病房",
      "sfx": { "text": "啪！", "pos": "top-right" },
      "dialogue": [
        { "speaker": "母亲", "text": "签吧，就一个字的事。", "pos": "top-right", "type": "speech" }
      ]
    }
  ]
}
```

- `panels` 数量要等于 列×行。
- 可选 `focus: [0.5, 0.3]`：裁切焦点（横、纵 0—1），人脸被裁掉时调小第二个数。
- 图还没出时也可以先运行脚本，缺图的格会显示占位和画面描述，用来预览文字排版。

完整样例见 `examples/ep01-comic.json`。

## 交付前自检

- 最后一格是不是停在和正文结尾一样的钩子上？
- 每格是否只有一个动作？相邻两格景别是否不同？
- 每个气泡是否 ≤12 字？整张漫画的字是否少到扫一眼就能读完？
- 每格提示词里人物描述是否和外观卡一字不差？
- 负面提示里是否写了“不要文字、不要气泡”？
