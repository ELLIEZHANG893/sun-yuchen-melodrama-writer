# 题材公式库

每个公式给出：起手式（第 1 集怎么开）、压抑来源、底牌、爽点兑现方式、常用反转。写作时选 1 个主公式，最多叠加 1 个辅助元素（如“+ 萌宝”“+ 读心”）。榜单显示单一爽点越来越难打动观众，复合但不杂乱的设定更受欢迎；有日常感的小异能比纯系统面板更受欢迎。

## 女频

### 1. 真假千金 / 身份错位
- 起手式：真千金被接回豪门的第一天，假千金当众给她难堪。
- 压抑：家人偏心、被栽赃、被比较。
- 底牌：真千金另有本事（学霸、神医、大佬马甲）或掌握真相证据。
- 爽点：在家宴 / 学校 / 公司公开场合实力碾压，家人后悔。
- 反转：抱错是人为的；假千金背后有人指使；真千金其实不想回这个家。

### 2. 马甲文 / 隐藏大佬
- 起手式：被嫌弃“没用”的女主，接到一通只有大佬才能接的电话。
- 压抑：被看不起、被当成配不上男主。
- 底牌：多重身份（设计师、黑客、神医、某集团幕后老板），一集掉一个。
- 爽点：马甲在最需要的时候掉落，对手当场失语。
- 反转：男主早就知道她的马甲；她最大的马甲连自己都不知道。

### 3. 闪婚 / 先婚后爱
- 起手式：为了应付家里，和陌生人领证；对方的真实身份远超想象。
- 压抑：原生家庭逼婚、前任纠缠、婆家刁难。
- 底牌：老公的隐藏身份；她自己的事业能力。
- 爽点：被欺负时老公 / 她自己即时护短反击。
- 反转：这场闪婚是对方蓄谋已久；两人多年前见过。
- 注意：平台和观众更偏好女主能自己翻盘，不要只靠男主救。

### 4. 追妻火葬场
- 起手式：她提出离婚 / 签下协议的那一刻，或她在他面前“消失”的那天。
- 压抑：长期被忽视、被当替身、被误会。
- 底牌：她的离开本身；真相（当年救他的人其实是她）。
- 爽点：她过得越来越好，他越来越后悔。
- 反转：误会是第三者设计的；她早已不需要原谅。
- 注意：不美化家暴、强迫；“火葬场”重点写他的后悔和她的成长。

### 5. 重生复仇 / 恶毒女配觉醒
- 起手式：死去的那一秒，睁眼回到悲剧发生前的某个具体时间点。
- 压抑：前世的惨死记忆；今生仍在原轨道上的危险。
- 底牌：未来信息差。
- 爽点：抢在对手之前一步截断阴谋，对手的算计全部落空。
- 反转：重生的不止她一个；前世的仇人其实是被利用的。

### 6. 穿书 / 读心 / 听物（日常异能）
- 起手式：穿成书里炮灰的那天，听见了身边人 / 物件的心声。
- 压抑：原书剧情里她的死亡结局正在逼近。
- 底牌：只有她能听见的信息；对剧情走向的预知。
- 爽点：用听到的秘密化解危机、拆穿谎言，从被嫌弃到被全家宠。
- 反转：心声也会说谎；原书女主也有秘密。
- 限制：异能要有限制（只能听物件 / 一天一次 / 碰到才能听），否则没有悬念。

### 7. 女性成长 / 原生家庭突围
- 起手式：一个让人窒息的家庭场景（被逼让出机会、被要求给弟弟买房）。
- 压抑：控制型父母、PUA 职场、被定义的“乖”。
- 底牌：她自己的能力和一次决定。
- 爽点：第一次说“不”；凭本事拿回属于自己的东西。
- 反转：她以为的支持者其实是阻碍；最看不起她的人最后需要她。
- 参考方向：此类题材在 25—35 岁女性用户中受欢迎，情感真实比强爽点更重要。

### 8. 种田 / 年代 / 发配逆袭
- 起手式：被发配、被赶出家门、穿到荒年。
- 压抑：饥饿、贫穷、恶邻、极品亲戚。
- 底牌：现代知识、空间 / 系统、手艺。
- 爽点：一锅饭、一块地、一笔生意逐步把日子过好；当初看不起的人来求她。
- 反转：被发配的“罪人”身份是冤案；看似落魄的男人是隐藏的将军。

### 9. 律师 / 职业女强讨公道
- 起手式：一个具体的不公（被吞的遗产、欠了几十年的债）。
- 压抑：对方有钱有势、家族内部掣肘。
- 底牌：专业能力 + 一份证据。
- 爽点：法庭 / 谈判桌上一条条拆穿。
- 反转：最后一份证据来自意想不到的人。

## 男频

### 10. 隐藏神豪 / 装穷回家
- 起手式：主角穿着普通回老家 / 参加同学会，被亲戚同学嘲讽。
- 压抑：势利眼、退婚、看不起。
- 底牌：亿万身份；身份揭穿被刻意拖延。
- 爽点：豪车、合同、一个电话让对手当场变脸。
- 反转：嘲讽最狠的人，正是主角公司的员工 / 合作方。
- 注意：每次快被识破都要有合理的延后理由，不要太拙劣。

### 11. 平凡职业里的大佬（外卖员 / 保安 / 赘婿）
- 起手式：送外卖 / 站岗时被当众羞辱。
- 底牌：武力、医术、隐藏的组织身份。
- 爽点：在关键时刻出手救下大人物。
- 反转：羞辱他的人有求于他。

### 12. 系统 / 修仙 / 收徒逆袭
- 起手式：废灵根、被逐出宗门，脑中响起系统音。
- 底牌：系统奖励、逆天弟子、特殊体质。
- 爽点：大比上越级击败天才。
- 反转：废灵根才是最强体质；系统另有目的。
- 新鲜变体：“上交国家”式——主角背后是现代国家支援，制造反差笑点。

### 13. 末世 / 规则怪谈 / 无限流
- 起手式：一条违反常识的规则出现（“晚上 12 点后不要回答敲门声”）。
- 压抑：规则致死、队友背叛。
- 底牌：主角发现规则漏洞的能力、时停一类有限异能。
- 爽点：用规则反杀。
- 反转：规则是人写的；主角自己就是怪谈的一部分。

### 14. 穿越权谋 / 纨绔逆袭
- 起手式：穿成人人喊打的纨绔世子，或被迫冒充高门子弟。
- 底牌：现代知识、学识、对历史走向的了解。
- 爽点：朝堂 / 诗会上一鸣惊人。
- 反转：冒充的身份背后另有阴谋；“纨绔”是原主的伪装。
