# 人设库与人设共创

读者被一个角色打动，靠的不是“他很帅”，而是**画面里那些只属于他的细节**：小狗系男生蹲下来仰头看你，霸总半夜发来三十条消息，追星女孩抢票失败灵魂出窍，洛丽塔女孩下雨天先护住裙摆。本手册分三部分：

1. **人设共创**：先和用户一起把每个主要角色定义清楚（人设卡），再画。
2. **人设库**：常见人设在画面上怎么表现（外形、穿搭、体态、表情、画面细节、专属演出）。
3. **反差人设**：外在和内在不一样的角色，怎么用画面让读者看到反差。

人设卡确认后，再按 [character-design.md](character-design.md) 的八个设计轴落到外观卡，按 [design.md](design.md) 4.4 落到表演卡。

---

## 一、人设共创：先定义，再设计

### 人设卡

每个主要角色一张，和设定卡一起交给用户确认（SKILL.md 检查点 1）：

```text
【人设卡】姓名｜身份
人设类型：主类型（从人设库选）+ 反差（可选）
一句话：别人眼中的他 ——> 他真实的样子
外在：给世界看的样子（穿搭、体态、说话方式、社交面具）
内在：真实的性格；最在乎什么；最怕什么
反差：什么时候破防；破防时是什么样子（具体到一个画面）
爱好与圈子：二次元 / 追星 / 洛丽塔 / 健身 / 露营……写具体（原创的偶像、作品、角色名）
说话方式：口头禅、语气、打字习惯（只发语音 / 句句带波浪号 / 从不用标点）
画面细节：随身物、手机壳和壁纸、包上的挂件、工位或房间、常喝常吃的东西
心动时刻：读者会在哪一个画面被他打动（写成一格画面）
```

### 和用户一起定的方式

- 先根据故事给出**人设卡草案**，再问用户。不要让用户从零开始填。
- 一次只问一两个最关键的问题，给 2—4 个选项并说明差别。常问的：
  - “她的反差你更想要哪种？A 精致外表下的城中村博主（已有）；B 再加一层：嘴硬但其实特别怕被丢下；C 不加。”
  - “他的爱好想不想具体一点？比如偷偷玩乐高、追一个小众乐队、周末去钓鱼。”
  - “读者第一次为他心动，你希望是哪个画面？”
- 用户给的任何一个具体细节（“她喜欢洛丽塔”“他其实很黏人”）都要追问一层：**这个细节会在哪个画面里被看到？** 然后写进“画面细节”和“心动时刻”。
- 人设卡确认后记进 `story-bible.md`，并登记到 `cast-registry.md`。后面每一章的分镜都要至少用到一个这个角色的画面细节。

## 三、反差人设：外在和内在用画面分开

反差是最能打动人的地方，但前提是读者**先相信外在**，再看到内在。

### 写法：四步

1. **先立外在**（至少 2—3 格 / 2 个场景）：用他的穿搭、体态、默认表情和专属演出，把“看起来的样子”立稳。
2. **埋小破绽**：一个只有读者注意到的细节（手机屏幕一闪而过的东西、包里露出的一角、一个不符合人设的小动作）。
3. **破防时刻**：一格画风突变的画面，从写实切到 Q 版、从冷色切到暖色、背后出现幻影耳朵、表情强度从 1 跳到 5。
4. **立刻缩回去**：下一格又恢复外在的样子（嘴硬、整理领带、推眼镜），反差感最强。

## 四、人设怎么落到每一章

- 每一章的分镜里，每个主要角色至少出现一个**只属于他的画面细节**（小动作、随身物、专属演出）。
- 有反差的角色，前 3 章立外在、埋破绽，第一个破防时刻放在卡点附近；之后每 2—3 章破防一次，每次破防都要比上一次更大一点。
- 心动时刻写进节奏表：哪一章、哪一格。

## 五、边界

- 二次元、洛丽塔、追星都是正常的爱好和圈子，画面要尊重，不要画成被嘲笑的对象，也不要性化。洛丽塔、JK 风格的服装穿在成年人身上，按日常穿搭来画。
- 偶像、作品、角色都用原创的名字，不要出现真实明星或现有作品的角色。
- 恋爱线的角色都是成年人；未成年角色不进入恋爱或亲密画面。
- 阴郁、伤感可以画，但不要美化自伤；涉及这类内容时点到为止。
