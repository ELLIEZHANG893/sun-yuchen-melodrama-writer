# 封面手册

目标：在手机信息流里缩成拇指大小时，观众一眼看出 **谁、什么情绪、什么冲突**，并被片名勾住。

本 skill 不直接出图。你负责：从故事里提炼画面 → 写出可复制到任意图像工具的提示词 → 给出排版命令。片名和卖点由 `scripts/render_visuals.py cover` 叠加，图里不要出现任何文字。

## 输入

- 设定卡：一句话卖点、主角、对手、情感线、核心秘密、底牌。
- 角色外观卡（见 SKILL.md 第六步）。没有就先补。
- 用户指定的比例 / 平台 / 风格。没说就用默认值：3:4、彩色写实短剧海报风、出 3 个方案。

## 三个方向（默认每个方向出一个方案）

| 方向 | 画面核心 | 适合 |
|---|---|---|
| 人物对峙型 | 主角 C 位、正面或 3/4 侧脸；对手在身后或侧上方，形成压迫 | 复仇、打脸、豪门、婆媳、职场 |
| 情绪特写型 | 主角脸部大特写，一个强情绪（含泪冷笑、隐忍、狠决）+ 一个道具或伤痕 | 女频成长、虐恋、重生 |
| 悬念道具型 | 一个关键道具占画面中心（文件、戒指、钥匙、旧照片），人物只露手或剪影 | 悬疑、身份反转、秘密驱动 |

选方向的依据：哪个最能体现“一句话卖点”里的反差。卖点里有物件（配型单、遗嘱、退婚书）时，悬念道具型通常最强；卖点是人物关系时选对峙型。

## 构图规则

- **最多 3 个人物**。人一多，缩略图就糊。
- 主角的脸至少占画面高度的 1/4；对峙型里主角比对手大。
- **给片名留区域**：片名默认放下方 40% 区域，所以画面下方要相对简单（暗色衣服、桌面、地面、虚化背景）；需要片名在上方时，上方留天空、墙面或暗部。提示词里明确写出留白位置。
- 光线有方向：侧光、顶光、逆光比平光更有情绪。
- 道具上的字不要靠模型画：画“一张写满字的医院报告”，关键信息由副标题说出来。
- 一张图只讲一个冲突，不要把全剧剧情塞进去。

## 配色与氛围（按题材挑）

| 题材 | 主色 | 氛围词 |
|---|---|---|
| 复仇 / 打脸 | 暗红、黑、冷白 | 高反差、压迫、冷光 |
| 豪门 / 霸总 | 黑金、深蓝 | 奢华、克制、夜景 |
| 重生 / 逆袭 | 晨光金、清透蓝 | 破晓、新生、逆光 |
| 虐恋 | 灰蓝、雨夜 | 雨、玻璃反光、泪光 |
| 原生家庭 / 现实 | 医院冷绿、旧黄 | 写实、日光灯、生活感 |
| 男频逆袭 | 黑、电光蓝、橙 | 低角度仰拍、气势 |
| 甜宠 | 奶油白、粉橘 | 柔光、暖色、浅景深 |

## 提示词结构

按这个顺序写，每个方案给中文版和英文版各一份（不同工具对中英文的理解不同，用户挑能用的那个）：

```text
[画面类型] 竖版短剧海报 / vertical drama poster
[主体] 外观卡里的整串描述，原样复制
[动作表情] 一个动作 + 一个情绪
[其他人物] 位置、动作（最多 2 人）
[场景] 地点 + 1—2 个道具
[光线色调] 光的方向 + 主色
[镜头] 景别、角度、景深
[留白] 下方 40% 简洁偏暗，留给标题 / empty darker space in the lower 40% for a title
[风格] 写实电影感 / 国漫 / 韩漫，与全剧统一
[比例] 3:4
[负面] 不要文字、字母、水印、logo / no text, no letters, no watermark, no logo
```

比例在提示词里写一次，同时提醒用户在出图工具里把比例设成一样的值。

## 方案输出格式

```text
方案 A｜悬念道具型
画面：一句话描述
构图：主体位置 / 留白位置 / 片名位置（top 或 bottom）
配色：主色 + 强调色（强调色会用在卖点和标签上，给出色值）
中文提示词：……
英文提示词：……
排版命令：
python scripts/render_visuals.py cover --image cover-a.png \
  --title "片名" --tagline "一句话卖点" --tag "女频·逆袭" \
  --ratio 3:4 --position bottom --accent "#E8423F"
```

用户选定后，把方案写进 `story-bible.md` 的“封面”一节。

## 片名与卖点

- 片名 4—12 字，脚本会自动缩放成最多两行。片名太长时，给用户一个封面专用短片名。
- 副标题用一句话卖点，16 字以内，口语、有反差、不剧透最终真相。
- 标签 2—6 字，格式“频道·题材”，如“女频·复仇”“男频·重生”。
- 浅色画面用 `--theme light`（黑字），暗色画面用默认的 `--theme dark`（白字）。

## 边界

- 不使用真实明星、网红的脸或名字；不写“像某某演员”。
- 不模仿已有剧集、小说的海报构图和角色造型，不出现真实品牌 logo。
- 未成年角色不做任何性化呈现；暴力和伤痕点到为止，不出现血腥特写。
