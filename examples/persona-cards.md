# 示例：深圳都市故事的人设卡（草案，待用户确认）

> 接 `sample-foreshadowing.md`。按 `references/persona-library.md` 先写人设卡，再翻译成外观卡（v2 见 `cast-registry.md`）和表演卡。

```text
【人设卡】江遥｜南山品牌公司的品牌经理
人设类型：嘴硬精明的喜剧女主（主）+ 反差：精致白领 ↔ 城中村生活博主
一句话：别人眼中周末潜水、吃前海 brunch 的精致白领 ——> 住沙尾村月租 1500 的握手楼，靠一个匿名账号认真记录城中村的生活
外在：伪老钱风穿搭；说话带点刻意的从容；朋友圈只发精修图；谁都不让看到她的出租屋
内在：精明、能吃苦、记性好、对城中村有真感情；最在乎“被当成一个有价值的人”；最怕被看不起，更怕被同情
反差：一提到城中村、电费、租房，她就切换成“专业模式”，语速变快、眼神变尖，忘了装
爱好与圈子：拍城中村的街景和小店；收集各家肠粉店的点评；匿名账号“深圳城中村生活志”
说话方式：对外说话爱用“其实还好啦”；在账号上写东西又准又狠；微信从不发语音
画面细节：超大帆布托特包里装着换下来的平底鞋；手机相册里几千张城中村照片；出租屋窗台上一排捡来的多肉；永远在用的 19.9 团购券
心动时刻：她蹲在城中村巷口，给一个阿婆讲怎么看电表，抬头时发现梁屿在不远处看着她，没有拆穿
```

```text
【人设卡】梁屿｜硬件公司“拓界科技”创始人
人设类型：高冷吐槽系（主）+ 反差：毒舌甲方 ↔ 细心的老粉、没钱的创业者
一句话：别人眼中穿旧冲锋衣、说话不留情面的怪人老板 ——> 公司账上只剩三个月现金、三年前就在她账号下留言的“华强北 4 楼的人”
外在：话少、毒舌、一眼看穿别人；永远在修东西；对所有吹捧免疫
内在：细心、念旧、守信；最在乎把产品做出来、不辜负跟着他的人；最怕自己是那个“装出来的人”
反差：被真诚地夸一句，耳朵立刻红；看到她的账号更新，会偷偷点赞，然后面无表情地关掉手机
爱好与圈子：华强北淘零件；周末去深圳湾骑车；收藏老式电子表
说话方式：一句话不超过十个字；“零秒。”“挺环保。”；从不用感叹号
画面细节：手指上的创可贴（焊板子烫的）；冲锋衣口袋里装着螺丝刀和润喉糖；手机关注列表里藏着“深圳城中村生活志”；会喝掉别人推开的免费饮料
心动时刻：他把她推开的那杯 19.9 特调一口喝完——读者在电梯反光里看到，她没有
```

## 落到表演卡（摘要）

| | 江遥 | 梁屿 |
|---|---|---|
| 外在演法 | 下巴微抬、营业式微笑、拽袖子藏手环 | 低头修东西、不正眼看人、死鱼眼 |
| 破防演法 | 专业模式：眼神变尖、手指比划、语速快（强度 3）；被拆穿：石化裂开（强度 5） | 被夸：表情不变、耳朵通红（强度 2）；憋笑：肩膀发抖（强度 3） |
| 招牌夸张脸 | 石化裂开；猫嘴得意闪光 | 死鱼眼 + 乌鸦；憋笑抖肩 |
| 专属演出 | 被拆穿时纯色块 + 大汗珠；专业模式时背景出现城中村线稿 | 冷蓝窗光 + 大留白 |
| 每章至少一个画面细节 | 帆布包里的平底鞋、相册里的城中村照片 | 创可贴、喝掉别人的饮料、偷偷点赞 |

## 需要和用户确认的一两件事

1. 江遥要不要再加一层反差：例如“嘴硬，但其实特别怕被丢下”，这样第 9 章低谷会更虐。
2. 梁屿的爱好用“收藏老式电子表”可以吗？它能接上他手上那块廉价电子表，也能在后面成为一份礼物。
