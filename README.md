# 孙式零度狗血写作器

一个用于创作第一人称狗血短剧、角色独白和连载故事的 Codex Skill。

核心写法是：情节极热，叙述极冷；用精确数字代替抒情，用物件与第三方劳动呈现关系，用短句、裸对话、沉默和回环制造余味。

## 安装

将本仓库复制到个人 Skills 目录：

```bash
git clone https://github.com/ELLIEZHANG893/sun-yuchen-melodrama-writer.git ~/.codex/skills/sun-yuchen-melodrama-writer
```

重新打开 Codex 后即可使用。

## 使用示例

- 用零度狗血风格写一篇第一人称豪门分手故事
- 把这段剧情改成 90 秒冷静独白短剧
- 为这个故事生成 10 集季纲，每集保留一个核心物件
- 模仿《我的女友景甜》的可观察文体特征改写，但不要复刻原文情节

## 文体原则

- 情绪越大，句子越平。
- 数字负责表达关系的不对称。
- 同一物件反复出现，并在结尾改变意义。
- 至少呈现一个维持主角世界的第三方劳动者。
- 关系结束后，让账单、提醒、排班或订单继续运行。
- 不搬用原文人物、金额、私密桥段、标志性物件或句子。

## 真实性与安全边界

本 Skill 主要研究一篇公开标注为虚构的长文，只提炼可观察的文本特征，不代表作者全部作品或真实人格，也不用于冒充任何现实人物发布内容。

默认人物、机构与事件均为虚构。涉及现实人物、公司、案件、犯罪、亲缘、财产或私生活时，应核验事实并优先使用不可识别的虚构替身。
